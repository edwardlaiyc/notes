## Forms

| | |
|---|---|
| `.md` | reads directly on GitHub |
| `.html` | the formatted page, best on the [site](https://edwardlaiyc.github.io/notes/) |
| `.tex` | the LaTeX source |

The two semesters are written differently, so not every topic has all three.
**Y1S2 is written in LaTeX** — the `.tex` is the source, and `.md`/`.html` are
generated from it. **Y1S1 is written in Markdown** — the `.md` *is* the source,
and only `.html` is generated beside it.

PDFs for every semester can be found in the [Google Drive](https://drive.google.com/drive/folders/1jBakz2SQzfH1xTFvTZ7bBeTaSbovUeek).
