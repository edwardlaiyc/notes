Definition

f:A→ℝ is continuous at a∈A if ∀ε>0,∃δ>0 such that f : A \to \mathbb{R} \text{ is continuous at } a \in A \text{ if } \forall \, \varepsilon > 0, \, \exists \, \delta > 0 \text{ such that }

∀x∈A,|x−a|<δ⟹|f(x)−f(a)|<ε.\forall x \in A, \; |x - a| < \delta \implies |f(x) - f(a)| < \varepsilon.

**A function is continuous at isolated points in the domain. Define an open interval such that a is the only element in the interval. Then f(a) = f(x) for all x in the interval.

If a is a limit point of the domain A,\text{If } a \text{ is a limit point of the domain A,}

f(x) is continuous on a set A⇔∀a∈A,limx→af(x)=f(a).f(x) \text{ is continuous on a set } A \;\Longleftrightarrow\;\forall \, a \in A, \; \lim_{x \to a} f(x) = f(a).

Proving that f is continuous at x=c means showing that lim(x → c){f(x)} = f(c).

f∈C(a)⇔f is continuous at a.f \in C(a) \;\Longleftrightarrow\; f \text{ is continuous at } a.

Elementary functions are continuous on their natural domains.

E.g. constants and powers of x, exponential, logarithm, (inverse) trigo.

Intermediate Value Theorem

If f(x)∈C([a,b]) and f(a)≠f(b),\text{If } f(x) \in C([a,b]) \text{ and } f(a) \ne f(b),

then ∀y∈(min⁡(f(a),f(b)),max⁡(f(a),f(b))),\text{then } \forall \, y \in \bigl( \min(f(a), f(b)), \max(f(a), f(b)) \bigr),

∃c∈(a,b) such that f(c)=y.\exists \, c \in (a,b) \text{ such that } f(c) = y.

Further implication: if f(a) and f(b) have different signs, there exists a root for f(x) = 0.
