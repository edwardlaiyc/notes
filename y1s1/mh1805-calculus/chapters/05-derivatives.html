Differentiability

f(x) is differentiable at a point x=a if the derivative at that point exists, i.e. the below limit exists.

f′(a)=ddxf(x)|x=a=limx→af(x)−f(a)x−a=limh→0f(a+h)−f(a)h.f'(a) = \frac{d}{dx} f(x) \bigg|_{x=a} = \lim_{x \to a} \frac{f(x) - f(a)}{x - a} = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}.

f′(x)=ddxf(x)=limh→0f(x+h)−f(x)hf'(x) = \frac{d}{dx} f(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}

Proving that f is not differentiable at a

Left-side not equals right-side limit

If limh→0−f(a+h)−f(a)h≠limh→0+f(a+h)−f(a)h,\text{If } \lim_{h \to 0^-} \frac{f(a + h) - f(a)}{h} \neq \lim_{h \to 0^+} \frac{f(a + h) - f(a)}{h},

then limh→0f(a+h)−f(a)h does not exist, and f is not differentiable at a.\text{then } \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} \text{ does not exist, and } f \text{ is not differentiable at } a.

Caveat

f′(a) may exist even if limx→af′(x) does not exist.f'(a) \text{ may exist even if } \lim_{x \to a} f'(x) \text{ does not exist.}

We find that f′(0)=0 (by definition of derivative).\text{We find that } f'(0) = 0 \text{ (by definition of derivative).}

However, for x≠0:\text{However, for } x \neq 0:

f′(x)=2xsin⁡(1x)−cos⁡(1x),f'(x) = 2x \sin\left(\frac{1}{x}\right) - \cos\left(\frac{1}{x}\right),

and the limit limx→0f′(x) does not exist.\text{and the limit } \lim_{x \to 0} f'(x) \text{ does not exist.}

Differentiability implies continuity

D(a)⊂C(a)D(a) \subset C(a)

  • Reason: To be differentiable, the graph must be smooth and unbroken (no sharp or discontinuous points).
  • Contrapositive: If f is not continuous at a, then f is not differentiable at a.\text{If } f \text{ is not continuous at } a, \text{ then } f \text{ is not differentiable at } a.
  • Reason: Not continuous → there exists some discontinuous points / sharp points at which the derivative does not exist.

Differentiation rules

Assuming f′,g′f', \; g' exist,

Sum rule (αf+βg)′=αf′+βg′(\alpha f + \beta g)' = \alpha f' + \beta g'
Product rule (fg)′=f′g+fg′(fg)' = f'g + fg'
Quotient rule (fg)′=f′g−fg′g2\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}
Chain rule (f(g))′=f′(g)⋅g′(f(g))' = f'(g) \cdot g'

Minima/maxima

x0∈A is a global maximum if ∀x∈A,f(x)≤f(x0).x_0 \in A \text{ is a global maximum if } \forall x \in A, \; f(x) \le f(x_0).

f:A→ℝ,x0 is a local maximum if ∃(a,b) such that f : A \to \mathbb{R}, \; x_0 \text{ is a local maximum if } \exists \, (a,b) \text{ such that }

x0∈(a,b) and f(x)≤f(x0) for all x∈(a,b)∩A.x_0 \in (a,b) \text{ and } f(x) \le f(x_0) \text{ for all } x \in (a,b) \cap A.

*We need to define an open interval, otherwise we can classify any point, x0, as a local max in a function like f(x) = x, by taking [x0 - 1, x0].

If a is a local maximum or minimum point of a function f,\text{If } a \text{ is a local maximum or minimum point of a function } f,

whose domain contains some interval (a−δ,a+δ) for some δ>0,\text{whose domain contains some interval } (a - \delta, a + \delta) \text{ for some } \delta > 0, and if f is differentiable at a,\text{ and if } f \text{ is differentiable at } a,

then f′(a)=0.\text{then } f'(a) = 0.

** the reverse implication is not true

** there can be other local minima/maxima where f’(c) ≠ 0.

Finding local minima/maxima:

  1. f’(c) = 0 (critical point)
  2. f’(c) d.n.e (critical point)
  3. End points of a closed interval.
  4. Isolated points in the domain.

Isolated points are both local maxima and minima. Use the definition of local minima/maxima to show.

To determine if each point is minima or maxima, use 1st or 2nd derivative test.

*If the result of 2nd derivative test is 0, we have no conclusion, use 1st derivative test.

Global minima/maxima will be the smallest/largest of all the local minima/maxima.

**If finding global minima/maxima on open interval, compare the local minima/maxima with lim⁡x→a+f(x),lim⁡x→b−f(x)\lim_{x \to a^+} f(x), \; \lim_{x \to b^-} f(x) or lim⁡x→+∞f(x),lim⁡x→−∞f(x)\lim_{x \to +\infty} f(x), \; \lim_{x \to -\infty} f(x).

L’hopital rule

If limx→af(x)g(x) is of indeterminate form [0/0] or [∞/∞],\text{If } \lim_{x \to a} \frac{f(x)}{g(x)} \text{ is of indeterminate form } [0/0] \text{ or } [\infty/\infty], and f,g∈D((a−δ,a+δ)\{a}) and g′(x)≠0,\text{and } f, g \in D((a - \delta, a + \delta) \setminus \{a\}) \text{ and } g'(x) \ne 0,

then limx→af(x)g(x)=limx→af′(x)g′(x).\text{then } \lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}.

If f(x)∈C([a,b]) and f∈D((a,b)),\text{If } f(x) \in C([a,b]) \text{ and } f \in D((a,b)), then there exists c∈(a,b) such that\text{then there exists } c \in (a,b) \text{ such that}

f′(c)=f(b)−f(a)b−a.f'(c) = \frac{f(b) - f(a)}{b - a}.

Special case (Rolle’s theorem):

If f(a)=f(b), then there exists c∈(a,b) such that f′(c)=0.\text{If } f(a) = f(b), \text{ then there exists } c \in (a,b) \text{ such that } f'(c) = 0.

Corollaries:

  1. If f′(x)=0 on an interval, then f is constant on that interval.\text{If } f'(x) = 0 \text{ on an interval, then } f \text{ is constant on that interval.}
  2. If f′=g′ on an interval, then f=g+C on that interval.\text{If } f' = g' \text{ on an interval, then } f = g + C \text{ on that interval.}
  3. If f∈D((a,b)), then if f′(x)≥0,f is increasing.\text{If } f \in D((a,b)), \text{ then if } f'(x) \ge 0, \; f \text{ is increasing.}

Similar for strictly increasing, decreasing etc.

Cauchy MVT

If f,g∈C([a,b]) and f,g∈D((a,b)),\text{If } f, g \in C([a,b]) \text{ and } f, g \in D((a,b)),

then there exists some c∈(a,b) such that\text{then there exists some } c \in (a,b) \text{ such that}

f′(c)(g(b)−g(a))=g′(c)(f(b)−f(a))f'(c)\bigl(g(b) - g(a)\bigr) = g'(c)\bigl(f(b) - f(a)\bigr)

This is a general form of MVT, with g(x)=x we get the original MVT.

Concavity

A function f(x) is concave upward on the interval I if and only if\text{A function } f(x) \text{ is concave upward on the interval } I \text{ if and only if}

for any a<x<b in I,f(x)−f(a)x−a<f(b)−f(a)b−a.\text{for any } a < x < b \text{ in } I, \; \frac{f(x) - f(a)}{x - a} < \frac{f(b) - f(a)}{b - a}.

Can be derived from: f(x)<f(b)−f(a)b−a(x−a)+f(a)f(x) < \frac{f(b) - f(a)}{b - a} (x - a) + f(a)

Similar for concave downward.

A point of inflection is where the concavity changes. At an inflection point, f″(x)=0f''(x) = 0 or f″(x)f''(x) does not exist.

However, f″(a)=0⇏af''(a) = 0 \not\Longrightarrow a is an inflection point.

Counter-example: Consider f(x)=x4f(x) = x^4. f″(0)=0f''(0) = 0 but x=0x = 0 is not an inflection point.

We need to check the concavity just before and just after the point where f″=0f''=0 or d.n.e.

2nd derivative test

If f(x)∈C2(I) and f″>0, it is concave upward; if f″<0, it is concave downward.\text{If } f(x) \in C^2(I) \text{ and } f'' > 0, \text{ it is concave upward; if } f'' < 0, \text{ it is concave downward.}

Suppose f′(a)=0, then if f″(a)>0,a is a local minimum.\text{Suppose } f'(a) = 0, \text{ then if } f''(a) > 0, \; a \text{ is a local minimum.}
