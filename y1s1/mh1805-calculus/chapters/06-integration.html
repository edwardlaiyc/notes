Riemann sum

∫abf(x)dx=limΔx→0∑i=1nf(xi*)Δxi,where Δx=max⁡(Δxi),i=1,2,…,n.\int_a^b f(x) \, dx = \lim_{\Delta x \to 0} \sum_{i=1}^{n} f(x_i^*) \, \Delta x_i, \quad \text{where } \Delta x = \max(\Delta x_i), \; i = 1, 2, \ldots, n.

where xi*∈[ai−1,ai] and a=a0<a1<⋯<an=b.\text{where } x_i^* \in [a_{i-1}, a_i] \text{ and } a = a_0 < a_1 < \cdots < a_n = b.

Choosing n equally spaced points, we get Δxi=b−an=Δx,\text{Choosing } n \text{ equally spaced points, we get } \Delta x_i = \frac{b - a}{n} = \Delta x,

and ∫abf(x)dx=limn→∞b−an∑i=1nf(xi*).\text{and } \int_a^b f(x) \, dx = \lim_{n \to \infty} \frac{b - a}{n} \sum_{i=1}^{n} f(x_i^*).

Properties

Continuity implies integrability

If f is continuous on [a,b], then it is integrable on [a,b].\text{If } f \text{ is continuous on } [a,b], \text{ then it is integrable on } [a,b].

Reason: Continuous function has unbroken graph, which means we can find the area under it.

Integrable functions need not be continuous.

Reason: The area under the graph can continue accumulating even across discontinuous points.

**For non-continuous f, the integral F is continuous. F is differentiability only if f is continuous (area has no sharp turning points).

Integrability and boundedness

If f is integrable on [a,b], it is bounded on [a,b],\text{If } f \text{ is integrable on } [a,b], \text{ it is bounded on } [a,b],

and is continuous on [a,b] except at finitely many points.\text{and is continuous on } [a,b] \text{ except at finitely many points.}

This means an unbounded function is non-Reimann integrable; and a function with infinitely many discontinuous points is non-integrable.

Comparing area under graphs

If f,g are both integrable on [a,b] and f(x)≤g(x), then ∫abf(x)dx≤∫abg(x)dx.\text{If } f, g \text{ are both integrable on } [a,b] \text{ and } f(x) \le g(x), \text{ then } \int_a^b f(x) \, dx \le \int_a^b g(x) \, dx.

Improper integrals

∫a+∞f(x)dx=limR→+∞∫aRf(x)dx\int_a^{+\infty} f(x) \, dx = \lim_{R \to +\infty} \int_a^{R} f(x) \, dx

LHS is an improper integral. If the RHS limit exists, the improper integral converges.
