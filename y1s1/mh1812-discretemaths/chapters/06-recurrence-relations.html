Linear recurrence relation

Linear recurrence relation of order k is of the form: \text{Linear recurrence relation of order } k \text{ is of the form: }

an=c1an−1+c2an−2+…+ckan−k+da_n = c_{1}a_{n-1} + c_{2}a_{n-2} + \ldots + c_{k}a_{n-k} + d

If d=0, the relation is homogenous.\text{If } d=0\text{, the relation is homogenous.}

Non-homogenous

Exponential constant

Solve the linear recurrence relation an=3an−1−2an−2+3n+1.\text{Solve the linear recurrence relation } a_n = 3a_{n-1} - 2a_{n-2} + 3n + 1.
