Cartesian Product

A×B={(a,b)|a∈A,b∈B}A \times B = \{(a, b) \ | \ a \in A, b \in B\}

Power Set

𝒫(S)={A∣A⊆S}\mathcal{P}(S) = \{\, A \mid A \subseteq S \,\}

For set S with n elements, |𝒫(S)|=2n\text{For set S with } n \text{ elements, } \left| \mathcal{P}(S) \right| = 2^n

Partition

The partition of set A is the set of nonempty sets,{A1,…,An} where A1∪…∪An=A, and Ai∩Aj=⌀,∀i,j∈{1,…,n},i≠j\{A_1, \ldots, A_n\} \text{ where } A_1 \cup \ldots \cup A_n = A, \text{ and } A_i \cap A_j = \varnothing, \; \forall\, i,j \in \{1, \ldots, n\}, \; i \neq j
