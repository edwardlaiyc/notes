\subsection{Data Transfer Instructions}
Instructions that move data between registers and/or memory.
\subsubsection{Register Data Transfer}
\begin{itemize}
    \item MOV instruction utilises register direct or immediate addressing.
    \begin{figure}[H]
        \centering
        \includegraphics[width=0.7\textwidth]{images/mov-movs.png}
        \caption*{MOV/MOVS instruction.}
    \end{figure}
    \item MVN instruction inverts the source operand bitwise by moving
    into the destination register.
    \begin{figure}[H]
        \centering
        \includegraphics[width=0.7\textwidth]{images/movn.png}
        \caption*{MVN instruction.}
    \end{figure}
\end{itemize}

\subsubsection{Memory Data Transfer}
\begin{itemize}
    \item LDR accesses memory at effective address using indirect register
    addressing modes.
    \begin{figure}[H]
        \centering
        \includegraphics[width=0.9\textwidth]{images/ldr-instructs.png}
        \caption*{LDR/LDRB instruction.}
    \end{figure}
    \item STR copies data to effective address using indirect register addressing modes. 
    \begin{figure}[H]
        \centering
        \includegraphics[width=0.9\textwidth]{images/str-instructs.png}
        \caption*{STR/STRB instruction.}
    \end{figure}

\subsection{Program Control Instructions}
To disrupt the program's normal sequential flow, the contents of the 
Program Counter (PC) is modifed, either directly or by using Branch instruction.

\medskip
\noindent If a branch is executed based on some condition(s),
it is a Conditional Branch or Branch on Conditional Code (Bcc).

\medskip
\noindent If the condition in the conditional code (cc) is true, 
a displacement is added to the PC. Note that the PC value is 
8 bytes ahead of the current Bcc being executed.

\medskip
\noindent The displacement range is $\pm32$MB.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{images/bcc-table.png}
    \caption*{The 15 conditional codes. Each code will be prefixed with 'B' in the code.}
\end{figure}

Signed vs unsigned values
\begin{itemize}
    \item For testing signed values, use \textbf{GT, LT, GE, LE}.
    \item For testing unsigned values, use \textbf{HI, LO, HS, LS}.
\end{itemize}
