\noindent SUBS sets C=1 when no borrow (A - B, where A $>=$ B); clears C=0 if borrow (A - B, where A $<$ B).

\noindent Condition to set the flags:
\begin{itemize}
    \item N: MSB = 1.
    \item Z: All zero.
    \item V: MSB of result $\neq$ MSB of operands, where MSB of operands are the same.
    \item C: Bit carried out = 1.
\end{itemize}
