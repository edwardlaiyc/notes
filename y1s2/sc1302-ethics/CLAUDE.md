# SC1302 Ethics — notes + web-conversion

**Scope:** this file adds SC1302-specific instructions to the workspace-wide
`../../CLAUDE.md`. The shared web pipeline is documented in
`../../web-pipeline/README.md`.

## Source layout — a single monolithic article
Unlike the other courses (which are `subfiles` projects), SC1302's notes are
**one standalone `article`**: `ethics-test.tex` at the course root, compiling to
`ethics-test.pdf`. There is no `chapters/` source folder to edit and no `images/`
— the notes are pure prose (no figures, tables, or bytefields).

**Edit `ethics-test.tex` — it is the single source of truth.** The
`chapters/*.tex` files are **generated build artifacts** (see below); never edit
them by hand.

## Web version — one page per top-level section
The web build slices `ethics-test.tex` into one reading page per top-level
`\section`, so the subject reads as chapter-sized pages instead of one long page.

| Page | Built from | Contents |
|------|-----------|----------|
| `index.html` | `index.md` + `course.yml` | Overview: grouped navigation, About, SC1302 Ecosystem |
| `chapters/*.html` | one slice of `ethics-test.tex` each | Individual topic reading pages |

The six topics, in order: **Metaethics, Moral Relativism, Utilitarianism,
Deontology, Virtue Ethics** (numbered 1–5) and **Questions** (a review section,
unnumbered).

## Pipeline package (shared: `../../web-pipeline/`)
The build machinery is shared and topic-independent; see
`../../web-pipeline/README.md`. This course supplies only three files in its root:

| File (course root) | Role |
|------|------|
| `course.yml` | Course code/title and the navigation model (pandoc metadata). |
| `site.psd1` | Build manifest: a single `split` preprocess step (`Sections = 'plain'`, **auto mode** — one module per `\section`, slug derived from the heading, no `Modules` list) plus the ordered `Topics`. `publish.ps1` reads this. |
| `index.md` | Overview content: About and the separate SC1302 Ecosystem section. |
| `assets/style.css` | Generated: staged copy of the shared stylesheet. Do not edit — edit `../../web-pipeline/style.css`. |

`chapters/*.tex` are regenerated by the split step on every publish; treat them
as build output alongside `chapters/*.html` and `chapters/*.md`.

## Build
One topic (writes HTML/Markdown beside the generated source):
```powershell
..\..\web-pipeline\build.ps1 -Source .\chapters\metaethics.tex
```
Whole site (runs the split, builds all six pages + overview):
```powershell
..\..\web-pipeline\publish.ps1
```
Note: a bare `build.ps1 -Source .\ethics-test.tex` would produce a single
whole-subject page and is **not** how this site is published — the split +
`publish.ps1` path is. To reslice after editing `ethics-test.tex`, just re-run
`publish.ps1`.

## Local preview
Serve from the course root so `assets/style.css` and page links resolve:
```powershell
python -m http.server 8765   # → http://127.0.0.1:8765/index.html
```
