11 Statistical Machine Learning

11.1 Classification Problem

Classification problem asks: Given an input, which category does it belong to?
In supervised learning context, we are given training data of pairs of input and the corresponding labels. D={(x1,y1),(x2,y2),…,(xn,yn)}D = \{(x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)\} The computer learns from these pairs and produces a hypothesis function hh, where h:x↦ŷh : x \mapsto \hat{y} The label set 𝒴\mathcal{Y} is finite. In comparison, regression problems’ outputs are continuous.
There are two flavours of classification:

  1. Binary classfication: there are exactly two possible labels. Implication is that we only need to model the probability of one class. Loss function is logistic loss.

  2. Multiclass classification: there are more than two labels. Implication is that we need to output a probability for each of the KK classes, and they must all sum to 1 using tools like the softmax function. Loss function is cross-entropy loss.

11.2 Binary classification - Logistic Regression

Logistic Regression is for binary classification.
Recall the sigmoid function that converts any real number into a probability: σ(z)=11+exp⁡(−z)\sigma(z) = \frac{1}{1 + \exp(-z)} When zz is positive and large, σ(z)≈1\sigma(z)\approx 1, when zz negative and large, σ(z)≈0\sigma(z)\approx 0, when z=0,σ(z)=0.5z=0, \sigma(z)=0.5.
In effect, it acts as a squashing function.
The probabilistic model is (where ww are the weights/parameters and hw(x)h_w(x) is the linear scoring function), p(y=+1|x,w)=σ(hw(x)),p(y=−1|x,w)=1−σ(hw(x))p(y = +1|x, w) = \sigma(h_w(x)), \quad p(y = -1|x, w) = 1 - \sigma(h_w(x)) Decision boundary: the set of points where hw(x)=0h_w(x)=0 is the hyperplane separating the two classes. Points on one side are classified +1, the other side -1.
The unified expression, for y∈{+1,−1}y\in \{+1, -1\}, is p(y|x,w)=11+exp⁡(−y⋅hw(x))p(y|x,w) = \frac{1}{1 + \exp(-y\cdot h_w(x))} Using MLE (by taking argmax of sum of log-probabilities), the MLE becomes: ŵ=arg⁡minw∈ℝd1n∑i=1nlog⁡(1+exp⁡(−yi⋅hw(xi)))\hat{w} = \arg\min_{w \in \mathbb{R}^d} \frac{1}{n} \sum_{i=1}^{n} \log(1 + \exp(-y_i \cdot h_w(x_i))) And the logistic loss is: l(y′,y)=log⁡(1+exp⁡(−y⋅y′))l(y', y) = \log(1 + \exp(-y \cdot y')) Intuition: y⋅y′y\cdot y' captures whether the prediction is correct. If y⋅y′y\cdot y' is positive, the prediction and true label agree ⟹\implies the loss is small. Otherwise y⋅y′y\cdot y' is large and negative ⟹\implies the loss is large.
Once ww is learned, predictions are made by: ŷ={+1if hw(x)≥0−1if hw(w)<0\hat{y} = \begin{cases} +1 & \text{if } h_w(x) \ge 0 \\ -1 & \text{if } h_w(w) < 0 \end{cases}

11.3 Multiclass classification - Softmax, Cross-entropy loss

Here we need to output a probability for each of the KK classes.
The hypothesis function outputs a vector of KK scores: hw(x)=(hw,1(x),…,hw,K(x))⊤:𝒳→ℝKh_w(x) = (h_{w,1}(x), \ldots, h_{w,K}(x))^\top : \mathcal{X} \to \mathbb{R}^K Each hw,kh_{w,k} is the raw score, or logit, for class kk.
Given these scores, the predicted class is just the one with the highest score: ŷ=arg⁡maxy∈𝒴hw,y(x)\hat{y} = \arg\max_{y \in \mathcal{Y}} h_{w,y}(x) That is for prediction. But for learning ww, we need to convert the scores to probabilities (to use MLE).
The softmax function converts the score vector into a valid probability distribution.
For a vector 𝒗=(v1,…,vK)\mathbf{v} = (v_1,\ldots,v_K), qv,k=exp⁡(vk)∑j=1Kexp⁡(vj)q_{v,k} = \frac{\exp(v_k)}{\sum_{j=1}^{K} \exp(v_j)} i.e. qv,1q_{v,1} corresponds to v1v_1.
Softmax preserves the ranking of scores, but squashes everything to make the sum = 1.
We can then write a probabilistic model. Assume the true structure on y∈{1,…,K}y \in \{1,\ldots,K\} given xx is: p(y∣x,w)=exp⁡(hw,y(x))∑k=1Kexp⁡(hw,k(x))p(y \mid x, w) = \frac{\exp(h_{w,y}(x))}{\sum_{k=1}^{K} \exp(h_{w,k}(x))} Note that this just softmax applied hw(x)h_w(x), evaluated at position yy, the true class.
Then apply MLE to find the ww that makes the training data most probable.
The log-likelihood for a single data point (x,yx, y) is: log⁡p(y∣x,w)=exp⁡(hw,y(x))∑k=1Kexp⁡(hw,k(x))=hw,y(x)−log⁡∑k=1Kexp⁡(hw,k(x))\log p(y \mid x, w) = \frac{\exp(h_{w,y}(x))}{\sum_{k=1}^K \exp(h_{w,k}(x))} = h_{w,y}(x) - \log \sum_{k=1}^{K} \exp(h_{w,k}(x)) Maximising this over all training data is equivalent to minimising its negative, i.e. minw1n∑i=1n{−hw,yi(xi)+log∑k=1Kexp(hw,k(xi))}⏟=ℓ(hw(xi),yi)\min_w \frac{1}{n} \sum_{i=1}^{n} \underbrace{\left\{ -h_{w,y_i}(x_i) + \log \sum_{k=1}^{K} \exp(h_{w,k}(x_i)) \right\}}_{= \ell(h_w(x_i),\ y_i)} This is the cross-entropy loss.
Intuition:

  • −hw,yi(xi)-h_{w,y_i}(x_i) pushes the score of the true class to be as large as possible.

  • log⁡Σexp⁡(hw,k(xi))\log \Sigma \exp(h_{w,k}(x_i)) grows whenever any score class gets large, acting as a penalty.

  • So the loss is minimized when the true class score is large relative to all other scores.

Context on the rough training flow:
With ww a set of KK weight vectors that parameterise the hypothesis function. Initially random, ww is learned by repeating this loop:

  1. Feed each training example xix_i through hwh_w to get KK raw scores.

  2. Apply softmax to convert scores into probabilities.

  3. Since we know the true label yiy_i, compute the cross-entropy loss. How wrong was the model about the true class?

  4. Average the losses across all nn examples (ℒn(w)\mathcal{L}_n(w)).

  5. Compute the gradient ∇wℒn(w)\nabla_w \mathcal{L}_n(w).

  6. Update ww in the opposite direction: w←w−η∇w(L)nww \leftarrow w - \eta\nabla_w \mathcal(L)_n w.

11.3.1 Expected loss, KL Divergence

So far we are minimising the empirical loss (the avg loss over the training data).
But we care about how the model performs over all possible inputs, not just the ones we trained on.
The expected loss is the average loss over the true data distribution: ℒ(w)=𝔼(X,Y)[ℓ(hw(X),Y)]\mathcal{L}(w) = \mathbb{E}_{(X,Y)}[\ell(h_w(X), Y)] We get ℒ(w)=𝔼(X,Y)[ℓ(hw(X),Y)]=∫𝒳∑y=1Kℙ[Y=y∣X=x]log⁡ℙ[Y=y∣X=x]p(y∣x,w)ℙ[X=x]dx⏟KL-divergence−∫𝒳∑y=1Kℙ[Y=y∣X=x]log⁡ℙ[Y=y∣X=x]ℙ[X=x]dx⏟entropy of true distribution\begin{align*} \mathcal{L}(w) &= \mathbb{E}_{(X,Y)}[\ell (h_w (X), Y)]\\ &= \underbrace{\int_{\mathcal{X}} \sum_{y=1}^{K} \mathbb{P}[Y=y \mid X=x] \log \frac{\mathbb{P}[Y=y \mid X=x]}{p(y \mid x,w)} \mathbb{P}[X=x] \, dx}_{\text{KL-divergence}} \\ &\quad - \underbrace{\int_{\mathcal{X}} \sum_{y=1}^{K} \mathbb{P}[Y=y \mid X=x] \log \mathbb{P}[Y=y \mid X=x] \mathbb{P}[X=x] \, dx}_{\text{entropy of true distribution}} \end{align*} The second term does not depend on ww at all.
Therefore minimising the expected cross-entropy loss is equivalent to minimising just the KL divergence term. This means finding the ww that makes the model’s predicted distribution p(y|x,w)p(y|x,w) as close as possible to the true distribution P[Y=y|X=X]P[Y=y|X=X].

Recall that KL divergence measures the degree of discrepancy between two probability distributions pp and qq: DKL(p∥q)=∑k=1Kpklog⁡pkqkD_{\text{KL}}(p \| q) = \sum_{k=1}^{K} p_k \log \frac{p_k}{q_k} So minimising cross entropy is just minimising: DKL(ℙ[Y|X]∥p(⋅|X,w))D_{\text{KL}}(\mathbb{P}[Y|X] \| p(\cdot | X, w)) where p(⋅|X,w)p(\cdot | X, w) is the full probability distribution over all possible classes yy, given input XX and parameters ww.
So we are comparing the true distribution P[Y|X]P[Y|X] vs the model’s predicted distribution p(⋅|X,w)p(\cdot | X, w).

11.4 Loss functions

A loss function l(y′,y)l(y', y) measures the error between a prediction y′=hw(x)y' = h_w(x) and the true label yy. Training a model means finding the ww that minimizes the total loss over training data. Different problems require different loss functions.
A recap:
Regression problems: the output is a continuous value.
Squared loss: l(y′,y)=0.5(y−y′)2l(y', y) = 0.5(y - y')^2 Penalizes large errors heavily due to the square. Sensitive to outliers.

ϵ\epsilon-sensitive loss: l(y′,y)=max⁡{|y−y′|−ϵ,0}l(y', y) = \max\{|y - y'| - \epsilon, 0\} Ignores errors smaller than ϵ\epsilon - useful when small errors are acceptable.
Binary classification lossses Used when y∈{+1,−1}y\in\{+1, -1\}.
Logistic loss: l(y′,y)=log⁡(1+exp⁡(−yy′))l(y', y) = \log(1 + \exp(-yy')) The product yy′yy' captures correctness - positive means correct, negative means wrong.
Hinge loss: l(y′,y)=max⁡{1−yy′,0}l(y', y) = \max\{1 - yy', 0\} Used in Support Vector Machines (SVMs). Zero loss when the prediction is correct and confident (yy′≥1yy' \geq 1). Doesn’t care about how confident correct predictions are beyond a margin.
Exponential loss: l(y′,y)=exp⁡(−yy′)l(y', y) = \exp(-yy') Used in boosting algorithms. Penalizes wrong predictions extremely aggressively - more sensitive to outliers than logistic loss.

All binary classfication losses depend on the product yy′yy'. When yy′yy' is large and positive, it is a correct, confident prediction and the loss should be small.
Exponential loss grows fastest, logistic loss grows moderately, hinge loss is zero for sufficiently correct predictions, and linear otherwise.
Multiclass Classification Loss
Cross-entropy loss: ℓ(hw(x),y)=−hw,y(x)+log⁡∑k=1Kexp⁡(hw,k(x))\ell(h_w(x), y) = -h_{w,y}(x) + \log \sum_{k=1}^{K} \exp(h_{w,k}(x)) Minimizing this is equivalent to minimizing KL divergence from the true distribution.

11.5 Supervised learning framework

The goal of supervised learning is to find a hypothesis function hwh_w that performs well on new, unseen data.

11.5.1 Expected loss minimisation

The ideal objective is to minimise the expected loss: minw{ℒ(w)=𝔼(X,Y)[l(hw(X),Y)]}\min_w \{\mathcal{L}(w) = \mathbb{E}_{(X,Y)}[l(h_w(X), Y)]\} This means averaging over all possible inputs, weighted by how likely each input is to occur in the real world.
However, we don’t have every possible input, but only a finite training dataset. So we cannot compute ℒ(w)\mathcal{L}(w) directly.

11.5.2 Empirical loss minimisation

Instead, we approximate ℒ(w)\mathcal{L}(w) using the empirical loss over training data D={(xi,yi)}i=1nD = \{(x_i, y_i)\}^{n}_{i=1}: minw{ℒn(w)=1n∑i=1nl(hw(xi),yi)}\min_w \{\mathcal{L}_n(w) = \frac{1}{n} \sum_{i=1}^{n} l(h_w(x_i), y_i)\} This is just the average loss over the nn training examples. As nn grows, ℒn(w)\mathcal{L}_n(w) becomes a better approximation of ℒ(w)\mathcal{L}(w). But minimising the empirical loss does not guarantee minimizing the expected loss, because the training data is just a sample of the real world. If optimise too hard for that specific sample, the model learns the training data rather than the underlying true pattern. Hence overfitting: the empirical loss is very low but the expected loss remains high.

11.5.3 Overfitting

Overfitting occurs when the gap between empirical loss and expected loss is large. The model performs well on training data but poorly on new unseen data: |𝔼(X,Y)[l(ĥ(X),Y)]−1n∑i=1nl(ĥ(xi),yi)|\left| \mathbb{E}_{(X,Y)}[l(\hat{h}(X), Y)] - \frac{1}{n}\sum_{i=1}^{n} l(\hat{h}(x_i), y_i) \right| where ĥ\hat{h} is the hypothesis function learned from training data DD.
It happens when the model is too complex and has enough flexibility to memorise the training data rather than learn the underlying pattern.
Also, with more data, the empirical loss becomes a better approximation of the expected loss, reducting the gap. Overfitting is most dangerous when data is scarce relative to model complexity.
We can prevent it with appropriate modelling (choose model whose complexity matches the true structure of the problem) and regularisation (penalise model complexity during training, prevent ww from growing too large).

11.5.4 The Model

We want to find the best hwh_w, but there are infinite functions. So we restrict the search to a model, i.e. a specific family of functions parameterised by ww: ℋ={hw:𝒳→𝒴∣w∈Ω⊂ℝp}\mathcal{H} = \{h_w : \mathcal{X} \to \mathcal{Y} \mid w \in \Omega \subset \mathbb{R}^p\} We decide a shape for the function output first, then training just finds the best version of that shape.
Example - we choose a linear function for the model: hw(x)=w⊤x+bh_w(x) = w^\top x + b. Then we restrict the search to only straight lines. Even if the true relationship is curved, the model will never capture it. This is bias.
On the other hand, if we choose a complex model like deep neural network, it can represent almost any function, but it has so many parameters that it can memorise the training data. This is variance.

11.6 Regularisation

Overfitting happens when the model is too complex. Regularisation is one way to fix this by penalising complexity directly in the training objective.
minwℒn,λ(w)=1n∑i=1nl(hw(xi),yi)+λ2∥w∥22\min_w \mathcal{L}_{n,\lambda}(w) = \frac{1}{n} \sum_{i=1}^{n} l(h_w(x_i), y_i) + \frac{\lambda}{2} \|w\|_2^2 By adding the regularisation term, it pushes ww to stay small.
λ\lambda is the regularisation coefficient.

  • λ\lambda too large: regularisation dominates and model may be too simple. May cause underfitting.

  • λ\lambda too small: empirical loss dominates and model may get too complex. May cause overfitting.

Hence choosing the right λ\lambda is a hyperparameter tuning problem.
Common regularisation terms:
L2 Regularisation (Ridge): ∥w∥22=∑j=1pwj2\|w\|_2^2 = \sum_{j=1}^{p} w_j^2 Penalizes large weights by squaring them. Shrinks all weights uniformly toward zero but never exactly to zero. Good when all features are expected to contribute something.
L1 Regularisation (Lasso): ∥w∥1=∑j=1p|wj|\|w\|_1 = \sum_{j=1}^{p} |w_j| Penalizes weights by their absolute value. Tends to push weights to exactly zero — effectively removing irrelevant features from the model. Good when you expect only a few features to matter (sparsity).
Elastic Net: α∥w∥1+1−α2∥w∥22,α∈(0,1)\alpha \|w\|_1 + \frac{1-\alpha}{2} \|w\|_2^2, \quad \alpha \in (0,1) A combination of L1 and L2. α\alpha controls the mix between the two. Useful when you want some sparsity (L1) but also stable shrinkage (L2).

11.7 Bias-variance tradeoff

Model complexity is defined as the diversity of functions contained in the model class ℋ\mathcal{H}. A model GG is more complex than ℋ\mathcal{H} if ℋ⊂G\mathcal{H} \subset G.
For example, a polynomial model is more complex than a linear model because every linear function is a polynomial, but not every polynomial is linear.
Bias measures how wrong the model is on average due to its simplifying assumptions. High complexity→Low bias\text{High complexity} \rightarrow \text{Low bias} Variance measures how much your learned model changes depending on the training data. High complexity→High variance\text{High complexity} \rightarrow \text{High variance} Complex model has more parameters, more sensitive to the specific training data.
The expected loss can be decomposed into bias and variance: ℒ(w)≈Bias2+Variance\mathcal{L}(w) \approx \text{Bias}^2 + \text{Variance} We want the optimal complexity where the total expected loss is minimized.

11.8 Model selection

We know there is an optimal model complexity. To find it, we need to choose the model class to use, the number of parameters, the value of λ\lambda for regularisation etc.
These are hyperparameters, i.e. settings that control the learning process itself, not learned from training.
We need a way to estimate the expected loss without using the test data.

11.8.1 Holdout Method

Split data into 2 parts: D=Dtrain∪DvalidationD = D_{\text{train}} \cup D_{\text{validation}}

  1. Train the model on DtrainD_{\text{train}}.

  2. Evaluate the average loss on DvalD_{\text{val}} (validation data).

  3. Use the validation loss as an estimate of the expected loss.

  4. Choose the hyperparameters that give the lowest validation data.

Since the model never sees DvalD_{\text{val}} during training, the validation loss is an unbiased estimate of how well the model generalises.
However, if the process is repeated many times trying different hyperparameters, the model starts to indirectly overfit to the validation data too. So the final evaluation must always be done on a completely separate test set that is never touched during model selection. D=Dtrain∪Dval∪DtestD = D_{\text{train}} \cup D_{\text{val}} \cup D_{\text{test}} Holdout method is also high variance: the validation estimate depends heavily on which specific examples ended up in DvalD_{\text{val}}.

11.8.2 Cross-validation (kk-fold CV)

Instead of one fixed split, rotate through kk different splits:

  1. Divide data into kk equal subsets.

  2. For each subset i=1,…,ki=1,\ldots,k:

    • Use subset ii as validation data.

    • Train on all other k−1k-1 subsets.

    • Record validation loss on subset ii.

  3. Average the kk validation losses to give a CV score. CV score=1k∑i=1kvalidation loss on fold i\text{CV score} = \frac{1}{k} \sum_{i=1}^{k} \text{validation loss on fold } i

Every example is used for both training and validation, just never at the same time. This makes CV more data-efficient and less sensitive to how the data is split than the holdout method.
Computing the CV score for each candidate value of the hyperparameter, we choose the value that gives the lowest CV score.
Leave-one-out CV (LOOCV)
A special case where k=nk=n. Each fold contains exactly one example as validation data, trained on all remaining n−1n-1 examples.
Advantage — uses almost all data for training each time, very low bias in the estimate.
Disadvantage — computationally expensive, requires n separate training runs.
LOOCV is useful when data is very scarce and you cannot afford to leave much out for validation.
