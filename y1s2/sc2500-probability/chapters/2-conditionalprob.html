2 Conditional Probability

2.1 Joint Probability

Considering 2 events A and B, the probability that both occur together is P(A∩B)P(A \cap B) Events A and B are independent iff P(A∩B)=P(A)P(B).P(A \cap B) = P(A)P(B). A set of events {Ai∣i∈I}\{A_i \mid i \in I\} is independent iff for every finite subset J ⊂\subset I, P(∩i∈JAi)=∏i∈JP(Ai).P(\cap_{i \in J}A_i) = \prod_{i \in J}P(A_i).

Eg: Flipping a coin twice, with
A = {Heads on first flip}, B = {Heads on second flip}
Then P(A∩B)=P(A)P(B)=(12)(12)=14P(A \cap B) = P(A)P(B) = (\frac{1}{2})(\frac{1}{2}) = \frac{1}{4}

Suppose some event B has occured, and the event of interest is A,
the conditional probability of A given B is PBA=P(A∣B)=P(A∩B)P(B) , for P(B)>0.P_{B}A = P(A \mid B) = \frac{P(A \cap B)}{P(B)}\text{ , for P(B)}> 0.

  3. If A1,A2,…A_1, A_2, \ldots are disjoint, then PB(⋃iAi)=∑iPB(Ai)P_B(\bigcup_{i}A_i) = \sum_{i}P_B(A_i) P((⋃iAi)∩B)P(B)=P(⋃i(Ai∩B))P(B)=∑iP(Ai∩B)P(B)=∑iP(Ai∩B)P(B)=∑iP(Ai∣B)\frac{P((\bigcup_{i}A_{i}) \cap B)}{P(B)} = \frac{P(\bigcup_{i}(A_{i} \cap B))}{P(B)} = \frac{\sum_{i}P(A_{i} \cap B)}{P(B)} = \sum_{i}\frac{P(A_i \cap B)}{P(B)} = \sum_{i}P(A_{i} \mid B)

By dividing by P(B)P(B), we normalise the universe to just B. When A occurs in this universe, B must also occur, hence we take P(A∩B)P(A \cap B).

If A and B are independent, P(A∣B)=P(A)P(B)P(B)=P(A)P(A \mid B) = \frac{P(A)P(B)}{P(B)} = P(A).

2.2.0.1 Multiplicative Rule

Following from the definition of conditional probaility, we have P(A∩B)=P(A∣B)P(B)P(A \cap B) = P(A \mid B)P(B) For independent events A and B, P(A∣B)=P(A)⇒P(A∩B)=P(A)P(B).P(A\mid B) = P(A) \Rightarrow P(A \cap B) = P(A)P(B).

Extending to multiple events, P(A∩B∩C)=P(A)⋅P(B∣A)⋅P(C∣B∩A)=P(A∣B∩C)⋅P(B∣C)⋅P(C)\begin{align*} P(A \cap B \cap C) &= P(A)\cdot P(B \mid A)\cdot P(C \mid B \cap A) \\ &= P(A \mid B \cap C) \cdot P(B \mid C) \cdot P(C) \end{align*}

2.2.0.2 Law of Total Probability

Let B1,B2,…,BkB_1, B_2, \ldots, B_k be a partition of sample space Ω\Omega.

(i.e. Bi∩Bj=∅,∀i≠j,and∪i=1kBi=Ω.B_i \cap B_j = \emptyset, \forall i \neq j, and \cup_{i=1}^{k}B_{i} = \Omega.)

Then for any event A, P(A)=∑i=1kP(A∣Bi)P(Bi)=P(A∩B1)+P(A∩B2)+…+P(A∩Bk)\begin{align*} P(A) &= \sum_{i=1}^{k} P(A \mid B_{i})P(B_{i})\\ &= P(A \cap B_1) + P(A \cap B_2) +\ldots + P(A \cap B_k) \end{align*} i.e. P(A) is the sum of probabilities in each scenario, weighted by each scenario’s probability.

2.2.0.3 Bayes’ Theorem

For P(B)>0P(B) > 0, P(A∣B)=P(B∣A)⋅P(A)P(B)=P(B∣A)⋅P(A)P(B∣A)⋅P(A)+P(B∣Ac)⋅P(Ac)P(A \mid B) = \frac{P(B \mid A)\cdot P(A)}{P(B)} = \frac{P(B \mid A)\cdot P(A)}{P(B\mid A)\cdot P(A) + P(B\mid A^c)\cdot P(A^c)}

Derivation: By Multiplicative Rule, P(A∩B)=P(A∣B)⋅P(B)=P(B∣A)⋅P(A)P(A \cap B) = P(A\mid B)\cdot P(B) = P(B\mid A)\cdot P(A) Rearranging, we get Bayes’ Theorem.

2.2.1 Naive Bayes classifier

Applications in supervised learning.

Goal: Classify an input (some object, e.g. an email, image, etc.) into one of several classes using probability.

Let CC be a class label (e.g. spam/not spam), and X=(x1,x2,…,xd)X = (x_1, x_2, \ldots, x_d) be observed features (certain words in the email).

By Bayes’ Theorem, P(C∣X)=P(X∣C)P(C)P(X)P(C \mid X) = \frac{P(X \mid C)P(C)}{P(X)}

To find the classifier ĉ:=arg⁡max⁡cP(C|X)=arg⁡max⁡cP(X|C)P(C).\hat{c} := \arg\max_c P(C|X) = \arg\max_c P(X|C)P(C).

Here, arg⁡max⁡cP(C∣X)\arg\max_c P(C \mid X) refers to finding the class cc that maximises the probability of the class given the data.

This is proportional to P(X∣C)P(C)P(X \mid C)P(C). We can ignore the denominator P(X)P(X), which is a constant for all classes, CC, during the maximisation process.

From the labelled data, it is easy to find P(C)P(C). The challenge is to find P(X∣C)=P(x1,x2,…,xd∣C).P(X \mid C) = P(x_1, x_2, \ldots, x_d \mid C).

The assumption of Naive Bayes is that all features are conditionally independent, given the class.

Then, we have P(x1,x2,…,xd∣C)=∏i=1dP(xi∣C)P(x_1, x_2, \ldots, x_d \mid C) = \prod_{i=1}^{d}P(x_i \mid C)

The Naive Bayes classifier is now ĉ:=arg⁡maxc∏i=1dP(xi∣C)P(C):=arg⁡maxcP(x1∣C)P(x2∣C)…P(xd∣C)P(C)\begin{align*} \hat{c} &:= \arg\max_c \prod_{i=1}^{d}P(x_i \mid C)P(C) \\ &:= \arg\max_c P(x_1 \mid C)P(x_2 \mid C)\ldots P(x_d \mid C)P(C) \end{align*}

Example calculation of an email spam filter:

From the data, we have P(spam)=0.3,P(not spam)=0.7P(x1∣spam)=0.8,P(x2∣spam)=0.5,P(x3∣spam)=0.3P(x1∣not spam)=0.2,P(x2∣not spam)=0.1,P(x3∣not spam)=0.2\begin{gather*} P(\text{spam}) = 0.3, \quad P(\text{not spam}) = 0.7 \\ P(x_1 \mid \text{spam}) = 0.8, \quad P(x_2 \mid \text{spam}) = 0.5, \quad P(x_3 \mid \text{spam}) = 0.3 \\ P(x_1 \mid \text{not spam}) = 0.2, \quad P(x_2 \mid \text{not spam}) = 0.1, \quad P(x_3 \mid \text{not spam}) = 0.2 \end{gather*}

Given an input feature {"free", "offer", "click"} ={x1,x2,x3}={1,1,0}= \{x_1, x_2, x_3\} = \{1, 1, 0\},

For class CC = spam, P(x1∣C)P(x2∣C)P(x3∣C)P(C)=0.8⋅0.5⋅0.7⋅0.3=0.084P(x_1\mid C)P(x_2\mid C)P(x_3\mid C)P(C) = 0.8\cdot0.5\cdot0.7\cdot0.3 = 0.084

For class CC = not spam, P(x1∣C)P(x2∣C)P(x3∣C)P(C)=0.2⋅0.1⋅0.8⋅0.7=0.0112P(x_1\mid C)P(x_2\mid C)P(x_3\mid C)P(C) = 0.2\cdot0.1\cdot0.8\cdot0.7 = 0.0112

Conclusion: Likely spam.
