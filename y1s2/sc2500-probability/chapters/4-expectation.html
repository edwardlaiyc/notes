4 Expectation

For a random variable XX, the expectation is Discrete: 𝔼[X]=∑xxpX(x)\text{Discrete: } \mathbb{E}[X]=\sum_xxp_X(x) Continuous: 𝔼[X]=∫−∞∞xfX(x)dx\text{Continuous: } \mathbb{E}[X]=\int_{-\infty}^{\infty}xf_X(x)\:\mathrm{d}x where pX(x)p_X(x) is the probability mass function (PMF) and fX(x)f_X(x) is the probability density function (PDF).

The expectation is the weighted average of all possible outcomes, where the weight is the probability of that outcome happening.

For a function g:ℝ→ℝg:\mathbb{R}\rightarrow\mathbb{R}, the expectation of g(X)g(X) is Discrete: 𝔼[g(X)]=∑xg(x)pX(x)\text{Discrete: } \mathbb{E}[g(X)]=\sum_xg(x)p_X(x) Continuous: 𝔼[g(X)]=∫−∞∞g(x)fX(x)dx\text{Continuous: } \mathbb{E}[g(X)]=\int_{-\infty}^{\infty}g(x)f_X(x)\:\mathrm{d}x Example XX is the outcome of a fair coin flip, X(H)=1X(H)=1, X(T)=0X(T)=0.
For a function g(X)=(X+2)2g(X)=(X+2)^2, g(1)=9g(1)=9, g(0)=4g(0)=4.
Then 𝔼[g(X)]=(9×0.5)+(4×0.5)=6.5\mathbb{E}[g(X)]=(9\times0.5) + (4\times0.5)=6.5.

Properties For a constant cc, we have that

  1. 𝔼[c]=c\mathbb{E}[c]=c
    ∵𝔼[c]=∑xc⋅pX(x)=c⋅∑xpX(x)=c⋅1=c\because \mathbb{E}[c]=\sum_xc\cdot p_X(x)=c\cdot \sum_xp_X(x)=c \cdot 1=c

  2. 𝔼[X+c]=𝔼[X]+c\mathbb{E}[X+c]=\mathbb{E}[X]+c
    ∵𝔼[X+c]=∑x(x+c)pX(x)=∑x(xpX(x))+c(pX(x))=𝔼[X]+c⋅1=𝔼[X]+c\because \mathbb{E}[X+c]=\sum_x(x+c)p_X(x)=\sum_x(xp_X(x))+c(p_X(x))=\mathbb{E}[X]+c\cdot 1=\mathbb{E}[X]+c

  3. 𝔼[cX]=c𝔼[X]\mathbb{E}[cX]=c\mathbb{E}[X]
    ∵𝔼[cX]=∑x(cx)pX(x)=c⋅∑xxpX(x)=c⋅𝔼[X]\because \mathbb{E}[cX]=\sum_x(cx)p_X(x)=c\cdot \sum_xxp_X(x)=c\cdot \mathbb{E}[X]

Multivariate expectation

For multiple random variables X,YX,Y and a function g:ℝ2→ℝg:\mathbb{R}^2\rightarrow\mathbb{R}, the expectation is Discrete: 𝔼[g(X,Y)]=∑x,yg(x,y)pX,Y(x,y)\text{Discrete: }\mathbb{E}[g(X, Y)]=\sum_{x, y}g(x, y)p_{X, Y}(x, y) Continuous: 𝔼[g(X,Y)]=∫−∞∞∫−∞∞g(x,y)fX,Y(x,y)dxdy\text{Continuous: }\mathbb{E}[g(X, Y)] = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty}g(x, y)f_{X, Y}(x, y)\:\mathrm{d}x\:\mathrm{d}y

Similarly, for constants c1c_1, c2c_2,
𝔼[c1X+c2Y]=c1𝔼[X]+c2𝔼[Y]\mathbb{E}[c_1X+c_2Y] = c_1\mathbb{E}[X] + c_2\mathbb{E}[Y] ∵𝔼[c1X+c2Y]=∑x∑y(c1x+c2y)⋅pX,Y(x,y)=∑x∑yc1x⋅pX,Y(x,y)+∑x∑yc2y⋅pX,Y(x,y)=∑xc1x(∑ypX,y(x,y))+∑yc2y(∑xpX,Y(x,y))=∑xc1x⋅pX(x)+∑yc2y⋅pY(y)=c1∑xxpX(x)+c2∑yypY(y)=c1𝔼[X]+c2𝔼[Y]\begin{align*} \because \mathbb{E}[c_1X+c_2Y] &= \sum_x\sum_y(c_1x + c_2y)\cdot p_{X,Y}(x,y) \\ &= \sum_x\sum_yc_1x\cdot p_{X,Y}(x,y) + \sum_x\sum_yc_2y\cdot p_{X,Y}(x,y) \\ &= \sum_xc_1x(\sum_yp_{X,y}(x,y)) + \sum_yc_2y(\sum_xp_{X,Y}(x,y)) \\ &= \sum_xc_1x\cdot p_X(x) + \sum_yc_2y\cdot p_Y(y) \\ &= c_1\sum_xxp_X(x) + c_2\sum_yyp_Y(y) \\ &= c_1\mathbb{E}[X] + c_2\mathbb{E}[Y] \end{align*}

Linearity of expectation For any two random variables XX and YY, 𝔼[X+Y]=𝔼[X]+𝔼[Y]\mathbb{E}[X+Y] = \mathbb{E}[X] + \mathbb{E}[Y] This rule holds true regardless of whether XX and YY are independent or completely dependent. Dependency affects variance, but it never breaks the linearity of expectation.

  1. Independent scenario: flip two fair coins, let X=1X=1 if Coin 1 = H, let Y=1Y=1 if Coin 2 = H.
    𝔼[X]=0.5\mathbb{E}[X] = 0.5 and 𝔼[Y]=0.5\mathbb{E}[Y] = 0.5.
    𝔼[X+Y]=(0×0.25)+(1×0.50)+(2×0.25)=1\mathbb{E}[X+Y] = (0 \times 0.25) + (1 \times 0.50) + (2 \times 0.25) = 1.

  2. Dependent scenario: Flip one fair coin, but count its result twice. Let X=1X = 1 if the coin is Heads, and let Y=XY = X.
    𝔼[X]=0.5\mathbb{E}[X] = 0.5 and 𝔼[Y]=0.5\mathbb{E}[Y] = 0.5.
    𝔼[X+Y]=(0×0.50)+(2×0.50)=1\mathbb{E}[X+Y] = (0 \times 0.50) + (2 \times 0.50) = 1.
