About

SC2006 Software Engineering, NTU AY25/26 Semester 1

High-yield revision notes authored from all 21 official lectures, complete tutorial problem sets (Tutorials 1 through 9), and recurring examination patterns.

Course Structure

The course spans 14 core chapters following the Software Development Life Cycle (SDLC):

  1. Overview and Exam Structure: Examination structure, 4-question breakdown, and syllabus map.
  2. Software Engineering and the Life Cycle: SDLC phases, Project Life Cycle (PLC), defect economics (Boehm’s escalation curve), Shift-Left principle.
  3. Requirements Elicitation: Elicitation techniques, Functional vs. Non-Functional Requirements (NFRs), verifiability heuristics (Tutorial 1).
  4. Use Case Model: System boundary, actors, <<include>> vs. <<extend>>, formal use case specifications (Tutorial 2).
  5. Software Requirements Specification (SRS): IEEE 830 standard structure, 8 quality attributes, bidirectional traceability.
  6. Conceptual Model: Domain class diagrams, associations, multiplicities, BCE robustness stereotypes (Tutorial 3).
  7. Dynamic Models: State machine diagrams (dialog maps) and swimlane activity diagrams (Tutorial 3).
  8. Software Process Models: Waterfall, V-Model, Prototyping, Incremental, and Boehm’s Spiral model (Tutorial 4).
  9. Agile, Extreme Programming and Scrum: Agile Manifesto, XP engineering practices (TDD, Pairing), Scrum ceremonies, velocity, and burn-down metrics (Tutorials 4 & 5).
  10. System Design and Software Architecture: Architectural styles, NFR trade-offs, 4-Layer architecture class mapping (Tutorial 6).
  11. Object Design and Design Patterns: Gang of Four patterns (Strategy, Observer, Factory Method, Decorator, Adapter) (Tutorials 6 & 7).
  12. Model-View-Controller (MVC): MVC component decoupling, event propagation trace, synergy with GoF patterns.
  13. Black-Box Software Testing: Equivalence class partitioning, boundary value analysis triplets, defensive test case matrix design (Tutorial 8).
  14. White-Box and Control Flow Testing: Control flow graphs (CFGs), Cyclomatic Complexity (CC=E−N+2=P+1CC = E - N + 2 = P + 1), coverage hierarchy, basis path testing (Tutorial 9).
  15. Software Maintenance and Evolution: Maintenance categories (Corrective, Adaptive, Perfective, Preventive), Lehman’s Laws, Code Smells and Refactoring.
  16. Exam Cheatsheet: Centralized revision playbook organized by Exam Question Type in Order (Q1 →\to Q4).
