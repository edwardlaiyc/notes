Data Link Layer (DLL): Medium Access Control & LANs

1. MAC Architecture & Random Access Fundamentals

1.1 The Multiple Access Problem

  • Shared Broadcast Medium: Multiple stations connect to a single shared physical channel.
  • Collision: When two or more stations transmit electromagnetic signals at the same time, the signals overlap and destroy both frames at the receiver.
  • No Out-of-Band Channel: All arbitration and coordination must happen over the shared data medium itself.
  • The “Genie-Aided” Ideal MAC:
    • When 1 node transmits, it achieves the full channel rate RR.
    • When MM nodes transmit, each gets an average fair rate of R/MR/M.
    • Fully decentralized (no master clock, no central coordinator).
    • Minimal protocol overhead.

1.2 The Three Design Pillars of Random Access MAC

Every random access MAC protocol makes three basic design choices:

  1. Carrier Sensing: Does the station listen before sending (e.g., blind sending in ALOHA vs. listen-before-talk in CSMA)?
  2. Transmission Policy: Once the channel is idle, how does it transmit (e.g., immediate sending vs. random backoff)?
  3. Collision Detection & Recovery: Does it detect collisions mid-transmission (e.g., CSMA/CD aborts immediately vs. ALOHA which transmits corrupted frames to the end)?

2. Random Access Protocols: The ALOHA Family

2.1 Slotted ALOHA

  • Operational Assumptions:
    • Time is sliced into discrete, synchronized slots equal to one frame transmission time (Tslot=TframeT_{\text{slot}} = T_{\text{frame}}).
    • Stations can start transmission only at the exact beginning of a time slot.
    • If two or more stations transmit in the same slot, a collision occurs. Stations detect the collision and retransmit in future slots with probability pp.
  • Throughput Derivation (SS):
    • Let there be NN active stations, each transmitting independently in a slot with probability pp.
    • Probability that station ii succeeds: Pr(Si)=p(1−p)N−1Pr(S_i) = p(1 - p)^{N-1}
    • Total probability that a slot contains a successful transmission: Pr(S)=∑i=1NPr(Si)=Np(1−p)N−1Pr(S) = \sum_{i=1}^N Pr(S_i) = Np(1 - p)^{N-1}
  • Large Network Limit (N→∞N \to \infty):
    • Define offered load G=NpG = Np (the average total transmission attempts generated by the network per slot).
    • Taking the limit as N→∞N \to \infty (where p=G/N→0p = G/N \to 0): S=limN→∞N(GN)(1−GN)N−1=Ge−GS = \lim_{N \to \infty} N\left(\frac{G}{N}\right)\left(1 - \frac{G}{N}\right)^{N-1} = G e^{-G}
  • Peak Throughput Optimization: dSdG=e−G−Ge−G=e−G(1−G)=0⟹G*=1.0\frac{dS}{dG} = e^{-G} - G e^{-G} = e^{-G}(1 - G) = 0 \implies G^* = 1.0 Smax=1.0⋅e−1=1e≈𝟎.𝟑𝟔𝟖(36.8%)S_{\max} = 1.0 \cdot e^{-1} = \frac{1}{e} \approx \mathbf{0.368} \quad (36.8\%)
  • Slot Outcome Distribution at Peak Operating Point (G=1.0G = 1.0):
    • Pr(Successful Slot)=1/e≈36.8%Pr(\text{Successful Slot}) = 1/e \approx 36.8\%
    • Pr(Empty / Idle Slot)=e−1≈36.8%Pr(\text{Empty / Idle Slot}) = e^{-1} \approx 36.8\%
    • Pr(Collision Slot)=1−2e−1≈26.4%Pr(\text{Collision Slot}) = 1 - 2e^{-1} \approx 26.4\%

2.2 Pure (Unslotted) ALOHA

  • Operational Rules:
    • Continuous time; no slotting, no global clock synchronization.
    • Stations transmit immediately whenever a frame arrives.
  • Vulnerable Time Window (2T2T):
    • Let frame transmission time be TT.
    • A target frame transmitted from t0t_0 to t0+Tt_0 + T is destroyed if another frame starts in:
      • (t0−T,t0)(t_0 - T, t_0): collides with the beginning of the target frame.
      • [t0,t0+T)[t_0, t_0 + T): collides with the end of the target frame.
    • Total vulnerable window is 2T2T (twice the frame duration).
  • Throughput Derivation (SS):
    • Using Poisson frame arrivals with average load GG attempts per frame time TT: Pr(No frame arrives in 2T)=e−2GPr(\text{No frame arrives in } 2T) = e^{-2G} S=Ge−2GS = G e^{-2G}
  • Peak Throughput Optimization: dSdG=e−2G(1−2G)=0⟹G*=0.5\frac{dS}{dG} = e^{-2G}(1 - 2G) = 0 \implies G^* = 0.5 Smax=0.5⋅e−1=12e≈𝟎.𝟏𝟖𝟒(18.4%)S_{\max} = 0.5 \cdot e^{-1} = \frac{1}{2e} \approx \mathbf{0.184} \quad (18.4\%)

3. Carrier Sense Multiple Access (CSMA)

3.1 Carrier Sense Principle & Vulnerable Window (τ\tau)

  • Core Rule: “Listen before talk” (LBT). A station senses the physical wire before transmitting:
    • Channel Idle: Transmit frame.
    • Channel Busy: Defer transmission.
  • Why Collisions Still Happen (Vulnerable Window τ\tau):
    • Carrier sensing cannot prevent all collisions because signals travel at finite speed (V≈2×108 m/sV \approx 2 \times 10^8\text{ m/s}).
    • Let τ\tau be the maximum one-way propagation delay between the two farthest stations.
    • If Station A transmits at t0t_0, Station B at the other end cannot detect the signal until t0+τt_0 + \tau. If Station B senses the wire during this window, it detects an idle line and starts transmitting, causing a collision.
    • Carrier sensing reduces the collision window from TframeT_{\text{frame}} (ALOHA) down to τ\tau (propagation delay).

3.2 CSMA Persistence Variants

Protocol Variant Channel State: Idle Channel State: Busy Tradeoff / Operational Characteristic
1-Persistent Transmits immediately (p=1p = 1). Continuously listens until idle, then transmits immediately with probability 1. Zero idle waiting time under light loads; high probability of collision under heavy loads when multiple stations defer during an ongoing frame.
Non-Persistent Transmits immediately. Abandons continuous listening, waits a random backoff delay, then re-senses the medium. Prevents simultaneous transmissions after a frame finishes; wastes channel capacity sitting idle during backoffs when the channel is free.
pp-Persistent (Slotted) Transmits with probability pp; defers to the next slot with probability 1−p1 - p. Continuously listens until idle, then applies the probability pp slot trial. Tunable performance via parameter pp. As p→1p \to 1, behaves like 1-persistent; as p→0p \to 0, collision rate drops, but idle slot latency increases.

4. CSMA with Collision Detection (CSMA/CD)

4.1 Collision Detection Principle

  • In pure CSMA, colliding stations continue sending their entire frame to completion, wasting channel time.
  • Listen While Talking: Transceivers monitor signal voltage/power while transmitting. If the detected signal power exceeds the station’s own transmitted signal power, a collision is detected.
  • Hubs (Layer 1) detect collisions when signals arrive simultaneously on two or more ports and output a collision presence signal to all ports.

4.2 Worst-Case Collision Detection Window (2τ2\tau)

  • Let τ\tau be the maximum one-way propagation delay between the two farthest stations (A and B).
  • Worst-Case Timeline:
    1. t=0t = 0: Station A starts transmitting on an idle channel.
    2. t=τ−ϵt = \tau - \epsilon: Right before A’s signal reaches Station B, B senses the medium idle and transmits.
    3. t=τt = \tau: Signals collide at Station B; B detects the collision immediately.
    4. t≈2τt \approx 2\tau: The corrupted signal wavefront travels all the way back to Station A; Station A detects the collision.
  • Core Invariant: In the worst case, detecting a collision takes twice the maximum propagation delay (2τ2\tau or 2a2a).
  • Handling Collisions:
    1. Abort Immediately: Stop transmitting the current data frame.
    2. Send Jam Signal (32–48 bits): Emit a brief jamming signal so all stations detect the collision and flush their buffers.
    3. Execute Backoff: Run Binary Exponential Backoff before re-sensing the line.

5. Wired LAN: Ethernet (IEEE 802.3)

5.1 Ethernet Frame Structure

  • Preamble (7 bytes): Pattern 10101010... used to synchronize receiver clock.
  • Start Frame Delimiter (SFD, 1 byte): Pattern 10101011 indicating the start of the MAC frame.
  • Destination Address (DA, 6 bytes / 48 bits): MAC address of the receiving interface.
  • Source Address (SA, 6 bytes / 48 bits): MAC address of the sending interface.
  • Length / Type (2 bytes): Length of payload or upper-layer protocol ID (e.g., IPv4, ARP).
  • Data + Padding (46 to 1500 bytes):
    • Maximum Transmission Unit (MTU) = 1500 bytes.
    • Minimum payload = 46 bytes (padded with dummy bytes if user data <46 bytes< 46\text{ bytes}).
  • Frame Check Sequence (FCS, 4 bytes): 32-bit CRC covering DA through Padding.

5.2 Destination Address Classification Rules

A 48-bit MAC address consists of 6 hexadecimal pairs: XX:XX:XX:XX:XX:XX.

  • The Inspection Rule: Look at the least significant bit (LSB) of the first byte (the 2nd hex character from the left):
    • Unicast (One-to-One): LSB is 0 ⟹\implies 2nd hex digit is even (0, 2, 4, 6, 8, A, C, E).
    • Multicast (One-to-Many): LSB is 1 ⟹\implies 2nd hex digit is odd (1, 3, 5, 7, 9, B, D, F).
    • Broadcast (One-to-All): All 48 bits are 1s ⟹\implies FF:FF:FF:FF:FF:FF.

5.3 Minimum Frame Size Derivation

  • The Constraint: A transmitting station only checks for collisions while it is actively sending bits. To guarantee that a sender detects a worst-case collision before it finishes transmission: Tframe≥2τend-to-endT_{\text{frame}} \ge 2\tau_{\text{end-to-end}} Lmin=2τend-to-end⋅RL_{\min} = 2\tau_{\text{end-to-end}} \cdot R
  • Standard 10 Mbps Ethernet Derivation:
    • Maximum round-trip time across 2500 m span: 2τ=51.2μs2\tau = 51.2\ \mu\text{s} (Slot Time).
    • Bit transmission time at R=10 MbpsR = 10\text{ Mbps}: 110×106=0.1μs/bit\frac{1}{10 \times 10^6} = 0.1\ \mu\text{s/bit}.
    • Minimum frame length: Lmin=51.2μs0.1μs/bit=512 bits=𝟔𝟒 𝐛𝐲𝐭𝐞𝐬L_{\min} = \frac{51.2\ \mu\text{s}}{0.1\ \mu\text{s/bit}} = 512\text{ bits} = \mathbf{64\text{ bytes}}
    • Mandatory MAC Header & Trailer: DA (6B)+SA (6B)+Length/Type (2B)+CRC FCS (4B)=𝟏𝟖 𝐛𝐲𝐭𝐞𝐬\text{DA (6B)} + \text{SA (6B)} + \text{Length/Type (2B)} + \text{CRC FCS (4B)} = \mathbf{18\text{ bytes}} (Preamble and SFD are physical synchronization bytes and do not count toward MAC frame size).
    • Minimum Data Payload: Minimum Payload=64 bytes−18 bytes=𝟒𝟔 𝐛𝐲𝐭𝐞𝐬\text{Minimum Payload} = 64\text{ bytes} - 18\text{ bytes} = \mathbf{46\text{ bytes}}

5.4 Binary Exponential Backoff (BEB) Algorithm

  • Contention Window Size: On collision ii, pick a random integer slot KK uniformly from: K∈{0,1,2,…,2k−1}where k=min⁡(i,10)K \in \{0, 1, 2, \ldots, 2^k - 1\} \quad \text{where } k = \min(i, 10)
  • Backoff Delay: Delay=K×51.2μs\text{Delay} = K \times 51.2\ \mu\text{s}
  • Abort Limit: After 16 failed attempts (attempts == 16), abort and report a network error.

6. Collision vs. Broadcast Domains

  • Collision Domain: A physical network segment where simultaneous transmissions collide.
    • Hubs/Repeaters (Layer 1): Forward bits out of all ports; merge all connected links into 1 single collision domain.
    • Switches/Bridges (Layer 2) & Routers (Layer 3): Buffer frames in internal memory; create a separate collision domain on every individual port.
  • Broadcast Domain: The network scope reached by a Layer 2 broadcast frame (FF:FF:FF:FF:FF:FF).
    • Hubs, Repeaters, Switches, and Bridges all forward broadcast frames across all ports (1 shared broadcast domain).
    • Routers block Layer 2 broadcasts; each router interface defines a separate broadcast domain.
Network Device Operating Layer Splits Collision Domains? Splits Broadcast Domains?
Hub / Repeater Layer 1 No (all ports share 1 domain) No (all ports share 1 domain)
Bridge / Switch Layer 2 Yes (each port is 1 domain) No (all ports share 1 domain)
Router Layer 3 Yes (each port is 1 domain) Yes (each interface is 1 domain)

7. Multi-Access Reservation Protocol (MARP)

7.1 Protocol Architecture

  • Purpose: Solves the problem of high collision rates in random access under heavy loads.
  • Two-Phase Transmission Cycle:
    • Phase 1 (Reservation Phase): Stations use short reservation mini-frames of time duration vv to contend for access.
    • Phase 2 (Data Phase): The winning station transmits its full data frame of time duration uu collision-free.
|<------------------------- Transmission Window ------------------------->|
+---------------------------------------------------+---------------------+
| Phase 1: Reservation Phase                        | Phase 2: Data Phase |
| Contention attempts using mini-frames of length v | Data frame length u |
| (Each attempt succeeds with probability S_r)      | (Collision-free)    |
+---------------------------------------------------+---------------------+

7.2 Window Duration & Utilization Formulas

  • Let SrS_r be the channel utilization of the reservation protocol used in Phase 1.
  • The number of reservation attempts XX required to succeed follows a geometric distribution: E[X]=1SrE[X] = \frac{1}{S_r}
  • Average reservation duration: Tres=E[X]×v=vSrT_{\text{res}} = E[X] \times v = \frac{v}{S_r}
  • Total average transmission window: Twindow=u+vSrT_{\text{window}} = u + \frac{v}{S_r}

Case 1: Reservation Frame Carries NO User Data (Standard Case)

S=Data Transmission TimeTotal Window Duration=uu+vSrS = \frac{\text{Data Transmission Time}}{\text{Total Window Duration}} = \frac{u}{u + \frac{v}{S_r}}

Case 2: Reservation Frame Carries User Data (Piggybacked)

If the mini-frame carries vv units of data, the remaining payload transmitted in Phase 2 is μ=u−v\mu = u - v: S=u(u−v)+vSrS = \frac{u}{(u - v) + \frac{v}{S_r}}

Maximizing MARP Throughput

max⁡(S)⇔max⁡(Sr)\max(S) \iff \max(S_r)

  • If Phase 1 uses Slotted ALOHA: Sr,max=1/e≈0.368S_{r,\max} = 1/e \approx 0.368 (when offered load G*=1.0G^* = 1.0).
  • For nn stations: station transmission probability is p*=G*/n=1/np^* = G^*/n = 1/n.

9. Exam Problem Archetypes

Archetype 1: Multi-Segment Minimum Frame Size Calculation

  • Problem: A CSMA/CD network operates at 20 Mbps:
    • Maximum cable length per segment: 200 m; propagation delay: 1μs1\ \mu\text{s} per 100 m.
    • Maximum number of repeaters between any two stations: 4 repeaters.
    • Internal delay through each repeater: 2μs2\ \mu\text{s}.
    • The network can link up to 5 cable segments. Find the minimum frame size required for CSMA/CD to work correctly.
  • Step 1: Compute total worst-case one-way propagation delay (τend-to-end\tau_{\text{end-to-end}}): Cable delay=5 segments×(200 m100 m×1μs)=5×2μs=10μs\text{Cable delay} = 5 \text{ segments} \times \left(\frac{200\text{ m}}{100\text{ m}} \times 1\ \mu\text{s}\right) = 5 \times 2\ \mu\text{s} = 10\ \mu\text{s} Repeater delay=4 repeaters×2μs=8μs\text{Repeater delay} = 4 \text{ repeaters} \times 2\ \mu\text{s} = 8\ \mu\text{s} τend-to-end=10μs+8μs=18μs\tau_{\text{end-to-end}} = 10\ \mu\text{s} + 8\ \mu\text{s} = 18\ \mu\text{s}
  • Step 2: Apply the CSMA/CD minimum transmission time invariant: Tframe≥2τend-to-end=2×18μs=36μsT_{\text{frame}} \ge 2\tau_{\text{end-to-end}} = 2 \times 18\ \mu\text{s} = 36\ \mu\text{s}
  • Step 3: Convert time to frame size in bits: Lmin=Tframe×R=36×10−6 s×20×106 bps=𝟕𝟐𝟎 𝐛𝐢𝐭𝐬(90 bytes)L_{\min} = T_{\text{frame}} \times R = 36 \times 10^{-6}\text{ s} \times 20 \times 10^6\text{ bps} = \mathbf{720\text{ bits}} \quad (90\text{ bytes})

Archetype 2: BEB Collision Event Probability (Three Stations)

  • Problem: Three stations (A, B, C) collide simultaneously on a 10BASE-T hub. Each station enters its 1st backoff retrial and chooses slot 0 or slot 1 with equal probability (p=0.5p = 0.5). Calculate the probability that the next active event on the channel is also a collision (idle slots do not count as events).
  • Step 1: Enumerate all joint slot selection outcomes (23=82^3 = 8 equally likely outcomes):
    • All choose 0: (0,0,0)⟹(0, 0, 0) \implies Collision in slot 0 (1 outcome).
    • Exactly two choose 0: (0,0,1),(0,1,0),(1,0,0)⟹(0, 0, 1), (0, 1, 0), (1, 0, 0) \implies Collision in slot 0 (3 outcomes).
    • Exactly one chooses 0: (0,1,1),(1,0,1),(1,1,0)⟹(0, 1, 1), (1, 0, 1), (1, 1, 0) \implies Success in slot 0 (3 outcomes).
    • None choose 0: (1,1,1)⟹(1, 1, 1) \implies Slot 0 is idle; all three transmit in slot 1 ⟹\implies Collision in slot 1 (1 outcome).
  • Step 2: Identify outcomes where the first event is a collision: Colliding outcomes=(0,0,0)+three of (2 zeros)+(1,1,1)=1+3+1=5 outcomes\text{Colliding outcomes} = (0,0,0) + \text{three of } (2 \text{ zeros}) + (1,1,1) = 1 + 3 + 1 = 5 \text{ outcomes}
  • Step 3: Calculate event probability: P(Next event is collision)=58=𝟎.𝟔𝟐𝟓(62.5%)P(\text{Next event is collision}) = \frac{5}{8} = \mathbf{0.625} \quad (62.5\%)

  • Problem: Two stations (A and B) collide and retransmit over a window of 2 slots (slot 0 and slot 1). Station A picks slot 0 with probability pp; Station B picks slot 0 with probability qq.
    1. If p=1/3p = 1/3 and q=2/3q = 2/3, what is the probability that the first active event on the channel is a success?
