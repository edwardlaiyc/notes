2. Tested MCQ Question Patterns & Plug-and-Chug Steps

Pattern 1: Maximum Serial Links for Given Reliability

  • Trigger: “A WAN path consists of nn serial links, each with failure probability pp. Find maximum nn to guarantee kk nines.”
  • Formula: (1−p)n≥1−10−k⟹n⋅p≤10−k⟹n≤10−kp(1 - p)^n \ge 1 - 10^{-k} \implies n \cdot p \le 10^{-k} \implies n \le \frac{10^{-k}}{p}.
  • Fast Test: p=10−4p = 10^{-4}, target 3 nines (1−10−31 - 10^{-3}): n≤10−310−4=𝟏𝟎 𝐥𝐢𝐧𝐤𝐬.n \le \frac{10^{-3}}{10^{-4}} = \mathbf{10\text{ links}}.

Pattern 2: Max Failures per Year from MTTR

  • Trigger: “Carrier-grade network (6 nines). MTTR is TrepairT_{\text{repair}}. Find maximum allowable non-overlapping failures per year.”
  • Execution Steps:
    1. Total annual downtime budget =10−6×31,536,000 s=31.536 seconds= 10^{-6} \times 31{,}536{,}000\text{ s} = 31.536\text{ seconds}.
    2. Max failures =⌊31.536MTTR⌋= \lfloor \frac{31.536}{\text{MTTR}} \rfloor.
  • Fast Test: For MTTR=10 s⟹⌊31.53610⌋=𝟑 𝐟𝐚𝐢𝐥𝐮𝐫𝐞𝐬/𝐲𝐞𝐚𝐫\text{MTTR} = 10\text{ s} \implies \lfloor \frac{31.536}{10} \rfloor = \mathbf{3\text{ failures/year}}.

Pattern 3: Parallel Redundancy Sizing

  • Trigger: “Link failure probability is pp. How many parallel links are needed to achieve availability ≥rtarget\ge r_{\text{target}}?”
  • Formula: pn≤(1−rtarget)p^n \le (1 - r_{\text{target}}).
  • Fast Test: p=0.3p = 0.3, target ≥0.99⟹0.3n≤0.01\ge 0.99 \implies 0.3^n \le 0.01:
    • n=1:0.3n=1: 0.3; n=2:0.09n=2: 0.09; n=3:0.027n=3: 0.027; n=4:0.0081≤0.01⟹𝒏=𝟒 𝐥𝐢𝐧𝐤𝐬n=4: 0.0081 \le 0.01 \implies \mathbf{n = 4\text{ links}}.

Pattern 4: Alternative Parallel Links (S&W vs. Sliding Window)

  • Trigger: “Link 1 uses Stop-and-Wait; Link 2 uses Sliding Window. Find min window size WW for Link 2 to outperform Link 1.”
  • Execution Steps:
    1. Compute S&W throughput on Link 1: Tput1=LTf1+2Tp1\text{Tput}_1 = \frac{L}{T_{f1} + 2T_{p1}}.
    2. Write sliding window throughput on Link 2: Tput2=W×LTf2+2Tp2\text{Tput}_2 = W \times \frac{L}{T_{f2} + 2T_{p2}} (assuming W<1+2aW < 1 + 2a).
    3. Set Tput2>Tput1\text{Tput}_2 > \text{Tput}_1 and solve for WW: W>Tf2+2Tp2Tf1+2Tp1⟹W=⌈W⌉.W > \frac{T_{f2} + 2T_{p2}}{T_{f1} + 2T_{p1}} \implies W = \lceil W \rceil.

3. High-Yield Conceptual Reference & Trivia

Historical Inventors / Internet Pioneers Matching

Protocol Behavior Across Normalized Delay (aa)

  • ALOHA Independence: ALOHA throughput is flat across varying aa because stations transmit blindly without sensing the carrier. Performance depends solely on frame transmission duration (TfT_f).
  • Why Slotted ALOHA Beats CSMA/CD at Large aa (a→1a \to 1 or a>1a > 1):
    • When aa is large, propagation delay (TpT_p) is long compared to transmission delay (TfT_f).
    • Carrier sensing detects outdated channel states, and CSMA/CD’s worst-case collision window (2a2a) wastes substantial channel capacity.
    • Slotted ALOHA confines collisions strictly to discrete slot boundaries, maintaining stable performance.
  • CSMA Persistence Comparison:
    • 1-Persistent: Senses idle →\to transmits immediately (p=1p=1). Zero idle delay under light loads; high collision rate under heavy loads.
    • Non-Persistent: Senses busy →\to random backoff before re-sensing. Greatly reduces collision under heavy load; wastes capacity idling under light load.
    • pp-Persistent: Slotted; transmits with probability pp. Balances low collisions and reduced idle latency by tuning pp.

Sliding Window Buffer Edge Mechanics

  • Sender Window:
    • Trailing edge (left) advances when valid ACKs are received.
    • Leading edge (right) advances when new frames are transmitted.
  • Receiver Window:
    • Trailing edge (left) advances when in-order frames are received and delivered to upper layer.
    • Leading edge (right) advances when ACKs are dispatched.

Pattern 6: HDLC Frame Parsing & Supervisory Control

  • Trigger: “Station B receives I(4,6)I(4, 6), then SREJ(6)\text{SREJ}(6) or RNR(4)\text{RNR}(4).”
  • Protocol Invariants:
    • In I(NS,NR)I(N_S, N_R), NSN_S is the frame’s sequence number; NRN_R acknowledges all frames up to NR−1N_R - 1 and requests frame NRN_R.
    • RR(n): Cumulative ACK; acknowledges up to n−1n-1, ready to receive nn.
    • RNR(n): Acknowledges all frames up to n−1n-1, but closes receive window (tells peer to stop sending).
    • SREJ(n): Out-of-order frame detected; retransmit only frame nn. Subsequent valid frames are buffered.
    • If B sent frames 6 and 7, and A returns SREJ(6)⟹\text{SREJ}(6) \implies Frame 6 was lost, but Frame 7 was received and buffered.

    2. Max Bitrate: Rmax=Lmin2τend-to-endR_{\max} = \frac{L_{\min}}{2\tau_{\text{end-to-end}}}.
    3. Max Segment Length: τend-to-end=Lmin2R⟹τcable=τend-to-end−∑τrepeaters.\tau_{\text{end-to-end}} = \frac{L_{\min}}{2R} \implies \tau_{\text{cable}} = \tau_{\text{end-to-end}} - \sum \tau_{\text{repeaters}}. Pattern 8: Backoff Contention Event Probabilities

  • Trigger: “Stations collide on a hub/bus. Find probability that the next event is success or collision.”

  • 3 Stations Colliding (Choices {0,1}\{0, 1\}):
    • Total outcomes =23=8= 2^3 = 8.
    • Collision outcomes: All pick 0 (1), two pick 0 (3), all pick 1 (1) ⟹5\implies 5 outcomes.

Pattern 9: Non-Uniform Packet Pipelining Delay

  • Trigger: “Packets of different sizes (e.g., 1000B, 4000B, 2000B) sent over intermediate routers.”
  • Method: Never use (P+k−1)Tx(P + k - 1)T_x. Construct a hop-by-hop forwarding timeline:
    • Store-and-Forward: Hop mm cannot transmit Packet ii until all bits of Packet ii have arrived from Hop m−1m-1.
    • Interface Contention: Hop mm cannot transmit Packet ii if it is still transmitting Packet i−1i-1.
  • Fast Test: Sizes 1000B (4 ms4\text{ ms}), 4000B (16 ms16\text{ ms}), 2000B (8 ms8\text{ ms}) at R=2 MbpsR = 2\text{ Mbps} across 2 intermediate routers (k=3k = 3 hops):
    • Hop 1: P1: [0,4][0, 4], P2: [4,20][4, 20], P3: [20,28][20, 28].
    • Hop 2: P1: [4,8][4, 8]. P2 arrives at 20 ⟹[20,36]\implies [20, 36]. P3 arrives at 28, but Hop 2 is busy until 36 ⟹\implies P3: [36,44][36, 44].

Pattern 10: Uniform Packet Pipelining Rate Dimensioning

  • Trigger: “Message size XX, split into PP packets with header HH over NN nodes. Find min data rate bb for total delay ≤T\le T.”

4. Rapid MCQ Elimination Rules

  • Destination MAC Parity (Inspect 2nd Hex Digit from Left):
    • X[Even]:XX:XX:XX:XX:XX (0, 2, 4, 6, 8, A, C, E) ⟹\implies Unicast.
    • X[Odd]:XX:XX:XX:XX:XX (1, 3, 5, 7, 9, B, D, F) ⟹\implies Multicast.
    • FF:FF:FF:FF:FF:FF ⟹\implies Broadcast.
    • Trap check: A Source MAC address is always unicast; its 2nd character can never be odd.
  • MAC Throughput Upper Bounds:
    • Pure ALOHA maximum throughput is 𝟏𝟖.𝟒%\mathbf{18.4\%} (12e\frac{1}{2e}).
    • Slotted ALOHA maximum throughput is 𝟑𝟔.𝟖%\mathbf{36.8\%} (1e\frac{1}{e}).
    • Eliminate any MCQ choice claiming higher throughput for ALOHA.
  • Layer 2 vs. Layer 3 Router Behavior:
    • Intermediate routers strip and discard the incoming Layer 2 header and trailer (DH/DTDH/DT) and build a new Layer 2 frame on every hop.
    • The Layer 3 Network header (NHNH), Transport header (THTH), and application data never change across intermediate hops.
  • Switching Crossover Invariant:
    • In the condition (k−1)pb<s(k - 1)\frac{p}{b} < s, total message length xx and propagation delay dd cancel out.
    • Altering message size xx has zero effect on whether packet switching is faster than circuit switching.
  • Collision vs. Broadcast Domains:
    • Hub / Repeater (Layer 1): 1 collision domain, 1 broadcast domain across all ports (splits nothing).
    • Switch / Bridge (Layer 2): Each physical port is an isolated collision domain; all ports share 1 broadcast domain.
    • Router (Layer 3): Each physical interface represents an isolated collision domain and an isolated broadcast domain.
  • Virtual Circuit vs. Circuit Switching:
    • Virtual circuits do not reserve dedicated physical bandwidth (bandwidth is dynamically shared).
    • Virtual circuit control planes do require connectionless packet routing capability to forward setup packets.

5. Exam Trap Radar

  • Hop Count vs. Node Count:
    • A network path with NN nodes has k=N−1k = N - 1 hops.
    • In pipelining formulas, use (P+k−1)(P + k - 1), never (P+N−1)(P + N - 1).
  • Byte to Bit Conversions:
    • Packet sizes and frame lengths are almost always given in Bytes, while transmission rates are given in bps (bits/second).
    • Multiply Bytes by 88 before calculating transmission delay: Tf=Bytes×8RT_f = \frac{\text{Bytes} \times 8}{R}.
  • Preamble Exclusion in Ethernet:
    • Total minimum frame size is 64 bytes (512 bits).
    • Preamble (7B) and SFD (1B) are physical-layer synchronization patterns and do not count toward the 64-byte frame minimum.
    • MAC overhead is 18 bytes (6B DA + 6B SA + 2B Type + 4B FCS) ⟹\implies Minimum payload is 46 bytes.
  • ARQ Window Sizing Upper Bounds:
    • Flow control only: W≤2kW \le 2^k.
    • Go-Back-N ARQ: W≤2k−1W \le 2^k - 1 (because Wrx=1W_{\text{rx}} = 1).
    • Selective Reject ARQ: W≤2k−1W \le 2^{k-1} (because Wrx=WtxW_{\text{rx}} = W_{\text{tx}}).
  • MARP Utilization Denominator:
    • If the reservation frame carries no data, denominator is u+vSru + \frac{v}{S_r}.
    • If the reservation frame piggybacks vv data bits, remaining data transmission duration is reduced to u−vu - v, making the denominator (u−v)+vSr(u - v) + \frac{v}{S_r}.
