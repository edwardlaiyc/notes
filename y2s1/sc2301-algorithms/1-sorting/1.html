Asymptotic Behaviour

Asymptotic Notation

Core Principle: Evaluates resource usage (time/space) as n→∞n \to \infty. Ignores machine constants (cc) and initialization noise (n0n_0).

Non-negativity: Note that 0 appears as a lower bound in the defintions as computational resources (time steps, memory) cannot be negative.

Proving T(n)=3n2+5n∈Θ(n2)T(n) = 3n^2 + 5n \in \Theta(n^2)

Need c1,c2,n0>0c_1, c_2, n_0 > 0 such that c1n2≤3n2+5n≤c2n2c_1 n^2 \le 3n^2 + 5n \le c_2 n^2 for all n≥n0n \ge n_0:

  1. Upper bound (OO): For n≥1n \ge 1, 5n≤5n2⟹3n2+5n≤8n2(c2=8,n0=1)5n \le 5n^2 \implies 3n^2 + 5n \le 8n^2 \quad (c_2 = 8, n_0 = 1).
  2. Lower bound (Ω\Omega): For n≥1n \ge 1, 5n≥0⟹3n2+5n≥3n2(c1=3,n0=1)5n \ge 0 \implies 3n^2 + 5n \ge 3n^2 \quad (c_1 = 3, n_0 = 1).
  3. Conclusion: 3n2≤3n2+5n≤8n23n^2 \le 3n^2 + 5n \le 8n^2 holds ∀n≥1⟹T(n)∈Θ(n2)\forall n \ge 1 \implies T(n) \in \Theta(n^2).

Essential Symmetry & Transitivity Relations

  • Intersection: Θ(g(n))=O(g(n))∩Ω(g(n))\Theta(g(n)) = O(g(n)) \cap \Omega(g(n))
  • Transpose Symmetry:
    • f(n)∈O(g(n))⇔g(n)∈Ω(f(n))f(n) \in O(g(n)) \iff g(n) \in \Omega(f(n))
    • f(n)∈o(g(n))⇔g(n)∈ω(f(n))f(n) \in o(g(n)) \iff g(n) \in \omega(f(n))
  • Transitivity:
    • If f(n)∈O(g(n))f(n) \in O(g(n)) and g(n)∈O(h(n))g(n) \in O(h(n)), then f(n)∈O(h(n))f(n) \in O(h(n)) (holds for O,Ω,Θ,o,ωO, \Omega, \Theta, o, \omega)
  • Reflexivity:
    • f(n)∈O(f(n))f(n) \in O(f(n)), f(n)∈Ω(f(n))f(n) \in \Omega(f(n)), and f(n)∈Θ(f(n))f(n) \in \Theta(f(n))

Asymptotic Notation Inside Expressions

  • Right-hand side: 4n2+12n+2=4n2+O(n)4n^2 + 12n + 2 = 4n^2 + O(n) means there exists an anonymous function f(n)∈O(n)f(n) \in O(n) replacing the lower-order terms.
  • Both sides: 4n2+Θ(n)=Θ(n2)4n^2 + \Theta(n) = \Theta(n^2) means for any chosen f(n)∈Θ(n)f(n) \in \Theta(n), there exists some g(n)∈Θ(n2)g(n) \in \Theta(n^2) satisfying the equality. The = denotes set containment (⊆\subseteq).

“Runtime is at least O(n2)O(n^2)”

  • Contradictory statement.
  • O(n2)O(n^2) sets an upper bound (at most c⋅n2c \cdot n^2), which contradicts the lower-bound phrase “at least”. To express a lower bound, state Ω(n2)\Omega(n^2) instead.
