# Asymptotic Behaviour

# Asymptotic Notation

**Core Principle:** Evaluates resource usage (time/space) as $n \to \infty$. Ignores machine constants ($c$) and initialization noise ($n_0$).

**Non-negativity:** Note that 0 appears as a lower bound in the defintions as computational resources (time steps, memory) cannot be negative.

### All the bounds

| Notation | Analogy | Set Definition | Limit Criterion ($\lim_{n \to \infty} \frac{f(n)}{g(n)}$) |
| :--- | :---: | :--- | :---: |
| $f(n) \in O(g(n))$ | $\le$ | $\exists\, c, n_0 > 0 \text{ s.t. } 0 \le f(n) \le c \cdot g(n), \quad \forall n \ge n_0$ | $< \infty$ |
| $f(n) \in \Omega(g(n))$ | $\ge$ | $\exists\, c, n_0 > 0 \text{ s.t. } 0 \le c \cdot g(n) \le f(n), \quad \forall n \ge n_0$ | $> 0$ |
| $f(n) \in \Theta(g(n))$ | $=$ | $\exists\, c_1, c_2, n_0 > 0 \text{ s.t. } 0 \le c_1 g(n) \le f(n) \le c_2 g(n), \quad \forall n \ge n_0$ | $c \in (0, \infty)$ |
| $f(n) \in o(g(n))$ | $<$ | $\forall\, c > 0,\, \exists\, n_0 > 0 \text{ s.t. } 0 \le f(n) < c \cdot g(n), \quad \forall n \ge n_0$ | $= 0$ |
| $f(n) \in \omega(g(n))$ | $>$ | $\forall\, c > 0,\, \exists\, n_0 > 0 \text{ s.t. } 0 \le c \cdot g(n) < f(n), \quad \forall n \ge n_0$ | $= \infty$ |

* **Key Difference ($O$ vs $o$, $\Omega$ vs $\omega$):** Big bounds require **at least one** constant $c$ ($\exists c$). Little bounds must hold for **every** constant $c > 0$ ($\forall c$).

### Proving $T(n) = 3n^2 + 5n \in \Theta(n^2)$

Need $c_1, c_2, n_0 > 0$ such that $c_1 n^2 \le 3n^2 + 5n \le c_2 n^2$ for all $n \ge n_0$:

1. **Upper bound ($O$):** For $n \ge 1$, $5n \le 5n^2 \implies 3n^2 + 5n \le 8n^2 \quad (c_2 = 8, n_0 = 1)$.
2. **Lower bound ($\Omega$):** For $n \ge 1$, $5n \ge 0 \implies 3n^2 + 5n \ge 3n^2 \quad (c_1 = 3, n_0 = 1)$.
3. **Conclusion:** $3n^2 \le 3n^2 + 5n \le 8n^2$ holds $\forall n \ge 1 \implies T(n) \in \Theta(n^2)$.

### Big $O$ — Asymptotic Upper Bound
Intuition: $O(g(n))$ represents a "ceiling" or worst-case growth rate. It describes the class of functions that grow no faster than $g(n)$ as $n \to \infty$.

Formally,
$$O(g(n)) = \{f(n) \mid \exists\, c > 0,\, n_0 > 0 \text{ such that } 0 \le f(n) \le c \cdot g(n) \text{ for all } n \ge n_0\}$$
Interpretation: There exists some scaled version $c \cdot g(n)$ that stays above or equal to $f(n)$ once $n$ is sufficiently large ($n \ge n_0$).
- $f(n)$: The actual running time of your algorithm.
- $g(n)$: The benchmark reference function (e.g., $n^2$, $n \log n$).
- $c$: A positive constant multiplier that scales $g(n)$. This allows the bound to ignore machine-dependent execution speeds.
- $n_0$: The threshold input size. The inequality does not need to hold for small inputs; it only needs to hold for all $n \ge n_0$.

Notational Convention: While technically $f(n) \in O(g(n))$ (since $O(g(n))$ is a set of functions), standard practice abuses notation by writing $f(n) = O(g(n))$.

### Big $\Omega$ (Omega) — Asymptotic Lower Bound
Intuition: $\Omega(g(n))$ represents a "floor" or best-case benchmark. It describes the class of functions that grow no slower than $g(n)$ as $n \to \infty$.

Formally,
$$\Omega(g(n)) = \{f(n) \mid \exists\, c > 0,\, n_0 > 0 \text{ such that } 0 \le c \cdot g(n) \le f(n) \text{ for all } n \ge n_0\}$$
Interpretation: There exists some scaled version $c \cdot g(n)$ that stays below or equal to $f(n)$ once $n$ is sufficiently large ($n \ge n_0$). Like Big $O$, we commonly write $f(n) = \Omega(g(n))$.

### Big $\Theta$ (Theta) — Asymptotically Tight Bound
Intuition: $\Theta(g(n))$ means $f(n)$ grows at essentially the same rate as $g(n)$. It sandwiches $f(n)$ between a lower multiple and an upper multiple of $g(n)$.

Formally,
$$\Theta(g(n)) = \{f(n) \mid \exists\, c_1 > 0,\, c_2 > 0,\, n_0 > 0 \text{ such that } 0 \le c_1 \cdot g(n) \le f(n) \le c_2 \cdot g(n) \text{ for all } n \ge n_0\}$$

Equivalence relation:
$$\Theta(g(n)) = O(g(n)) \cap \Omega(g(n))$$

- A function $f(n)$ is $\Theta(g(n))$ if and only if it is both $O(g(n))$ (bounded above by $g(n)$) and $\Omega(g(n))$ (bounded below by $g(n)$).

### Little $o$ — Strict Upper Bound
Intuition: Where Big $O$ means $\le$, Little $o$ means strictly $<$. The function $f(n)$ grows strictly slower than $g(n)$.

Formally,
$$o(g(n)) = \{f(n) \mid \forall\, c > 0,\, \exists\, n_0 > 0 \text{ such that } 0 \le f(n) < c \cdot g(n) \text{ for all } n \ge n_0\}$$

Key Difference from Big $O$:
- Big $O$ requires that the bound holds for at least one positive constant $c$.
- Little $o$ requires that the bound holds for every positive constant $c$, no matter how tiny ($c = 0.0001$, etc.). Eventually, as $n \to \infty$, $c \cdot g(n)$ still outgrows $f(n)$.

The limit test for Little $o$:
$$\lim_{n \to \infty} \frac{f(n)}{g(n)} = 0$$
Examples:
- $2n \in o(n^2)$ because $\lim_{n \to \infty} \frac{2n}{n^2} = \lim_{n \to \infty} \frac{2}{n} = 0$.
- $3n^2 \notin o(n^2)$ because $\lim_{n \to \infty} \frac{3n^2}{n^2} = 3 \neq 0$ (it is $O(n^2)$ and $\Omega(n^2)$, but not $o(n^2)$).

### Little $\omega$ (Omega) — Strict Lower Bound
Intuition: Where Big $\Omega$ means $\ge$, Little $\omega$ means strictly $>$. The function $f(n)$ grows strictly faster than $g(n)$.

Formally,
$$\omega(g(n)) = \{f(n) \mid \forall\, c > 0,\, \exists\, n_0 > 0 \text{ such that } 0 \le c \cdot g(n) < f(n) \text{ for all } n \ge n_0\}$$

The limit test for Little $\omega$:
$$\lim_{n \to \infty} \frac{f(n)}{g(n)} = \infty$$

### Asymptotic Relational Analogy & Key Properties

| Notation | Real-Number Analogy | Intuition | Formal Criterion / Limit Test |
| :--- | :---: | :--- | :--- |
| $f(n) \in O(g(n))$ | $f(n) \le g(n)$ | Upper bound (no faster than) | $\lim_{n \to \infty} \frac{f(n)}{g(n)} < \infty$ |
| $f(n) \in \Omega(g(n))$ | $f(n) \ge g(n)$ | Lower bound (no slower than) | $\lim_{n \to \infty} \frac{f(n)}{g(n)} > 0$ |
| $f(n) \in \Theta(g(n))$ | $f(n) = g(n)$ | Tight bound (grows as fast as) | $0 < \lim_{n \to \infty} \frac{f(n)}{g(n)} < \infty$ |
| $f(n) \in o(g(n))$ | $f(n) < g(n)$ | Strict upper bound (strictly slower) | $\lim_{n \to \infty} \frac{f(n)}{g(n)} = 0$ |
| $f(n) \in \omega(g(n))$ | $f(n) > g(n)$ | Strict lower bound (strictly faster) | $\lim_{n \to \infty} \frac{f(n)}{g(n)} = \infty$ |

#### Essential Symmetry & Transitivity Relations
* **Intersection:** $\Theta(g(n)) = O(g(n)) \cap \Omega(g(n))$
* **Transpose Symmetry:**
  * $f(n) \in O(g(n)) \iff g(n) \in \Omega(f(n))$
  * $f(n) \in o(g(n)) \iff g(n) \in \omega(f(n))$
* **Transitivity:** 
  * If $f(n) \in O(g(n))$ and $g(n) \in O(h(n))$, then $f(n) \in O(h(n))$ (holds for $O, \Omega, \Theta, o, \omega$)
* **Reflexivity:**
  * $f(n) \in O(f(n))$, $f(n) \in \Omega(f(n))$, and $f(n) \in \Theta(f(n))$

### Common Growth Rates (Fastest to Slowest Efficiency)

| Class Name | Notation | Growth Characteristic |
| :--- | :--- | :--- |
| **Constant** | $O(1)$ | Independent of input size |
| **Logarithmic** | $O(\log n)$ | Cuts problem space by factor each step |
| **Linear** | $O(n)$ | Directly proportional to input size |
| **Log-Linear** | $O(n \log n)$ | Typical optimal comparison sort bound |
| **Superlinear** | $O(n^{1+c})$ ($c > 0$) | Faster than linear, strictly sub-quadratic |
| **Quadratic** | $O(n^2)$ | Typical nested loop over same input |
| **Polynomial** | $O(n^k)$ ($k \ge 1$) | General polynomial growth |
| **Exponential** | $O(c^n)$ ($c > 1$) | Doubles/multiplies each added item |

### Asymptotic Notation Inside Expressions
* **Right-hand side:** $4n^2 + 12n + 2 = 4n^2 + O(n)$ means there exists an anonymous function $f(n) \in O(n)$ replacing the lower-order terms.
* **Both sides:** $4n^2 + \Theta(n) = \Theta(n^2)$ means for *any* chosen $f(n) \in \Theta(n)$, there exists some $g(n) \in \Theta(n^2)$ satisfying the equality. The `=` denotes set containment ($\subseteq$).

### "Runtime is at least $O(n^2)$"
* Contradictory statement.
* $O(n^2)$ sets an upper bound (at most $c \cdot n^2$), which contradicts the lower-bound phrase "at least". To express a lower bound, state $\Omega(n^2)$ instead.
