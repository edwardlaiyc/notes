Graphs model pairwise relationships between discrete objects across computer systems, from network topologies and dependency build graphs to routing engines and state machines. Traversal algorithms systematically visit every vertex and edge, establishing the foundation for shortest path algorithms (Dijkstra), minimum spanning trees (Prim, Kruskal), and cycle detection.

This chapter covers graph storage trade-offs (adjacency matrix vs. adjacency list), Breadth-First Search (BFS), Depth-First Search (DFS), edge classification (tree, back, forward, cross), cycle detection, and Topological Sorting of Directed Acyclic Graphs (DAGs).

1. Graph Representations: Matrix vs. List

A graph G=(V,E)G = (V, E) consists of a set of vertices VV and a set of edges E⊆V×VE \subseteq V \times V.

  • Undirected: (u,v)=(v,u)(u, v) = (v, u). Each undirected edge contributes 22 to the sum of vertex degrees: ∑v∈Vdeg⁡(v)=2|E|\sum_{v \in V} \deg(v) = 2|E|.
  • Directed: (u,v)(u, v) originates at uu and terminates at vv. Here ∑v∈Vout-deg(v)=∑v∈Vin-deg(v)=|E|\sum_{v \in V} \text{out-deg}(v) = \sum_{v \in V} \text{in-deg}(v) = |E|.
  • Density: A graph is sparse if |E|≪|V|2|E| \ll |V|^2 (e.g. |E|=O(|V|)|E| = O(|V|)), and dense if |E|≈|V|2|E| \approx |V|^2.

2. Breadth-First Search (BFS)

BFS explores a graph concentrically outward from a source vertex ss, discovering all vertices at distance kk before any vertices at distance k+1k + 1. It utilizes a FIFO Queue to manage the discovery frontier.

void BFS(const vector<vector<int>>& Adj, int s, int V) {
    vector<int> dist(V, -1);               // -1 denotes undiscovered (WHITE)
    vector<int> parent(V, -1);
    queue<int> Q;

    dist[s] = 0;
    Q.push(s);                             // Mark GRAY upon queue insertion

    while (!Q.empty()) {
        int u = Q.front();
        Q.pop();                           // u turns BLACK

        for (int v : Adj[u]) {
            if (dist[v] == -1) {           // v is WHITE (undiscovered)
                dist[v] = dist[u] + 1;
                parent[v] = u;
                Q.push(v);                 // v turns GRAY
            }
        }
    }
}

Structural Invariants of BFS

  1. Shortest Paths in Unweighted Graphs: For every vertex vv reachable from ss, dist[v] is the minimal number of edges from ss to vv.
  2. Monotonicity of Queue Distances: At any point, the queue contains vertices with distances either all equal to dd, or a sequence of dd followed by d+1d + 1.
  3. Black-White Invariant: A black vertex never has a white neighbor. The frontier of gray vertices completely isolates the finished black region from the unvisited white region.
Tutorial 4 Q4: Complexity Analysis of BFS on Adjacency Matrix vs. List

Question: The standard running time analysis of BFS assumes an adjacency list representation, achieving O(|V|+|E|)O(|V| + |E|).

  1. What is the running time of BFS if the input graph is represented by an adjacency matrix?
  2. Provide a formal step-by-step justification.

Solution:

  • (a) Running Time: Using an adjacency matrix, BFS requires Θ(|V|2)\Theta(|V|^2) time.

  • (b) Step-by-Step Derivation:

    1. Initialization: Initializing distance and parent arrays takes Θ(|V|)\Theta(|V|) time.
    2. Queue Operations: In a connected component, every reachable vertex enters and exits the FIFO queue at most once. For |V||V| vertices, total queue overhead is Θ(|V|)\Theta(|V|).
    3. Neighbor Exploration per Vertex:
      • In an adjacency matrix, finding the neighbors of a dequeued vertex uu requires scanning row uu across all |V||V| columns (v=0…|V|−1v = 0 \dots |V| - 1) to verify if A[u][v]≠0A[u][v] \ne 0.
      • This row scan takes Θ(|V|)\Theta(|V|) time per vertex, regardless of how many edges are actually incident on uu.
    4. Aggregation:
      • Since up to |V||V| vertices are dequeued, the total neighbor exploration cost is: ∑u∈VΘ(|V|)=|V|⋅Θ(|V|)=𝚯(|𝑽|𝟐).\sum_{u \in V} \Theta(|V|) = |V| \cdot \Theta(|V|) = \mathbf{\Theta(|V|^2)}.
    5. Total Running Time: Θ(|V|)+Θ(|V|)+Θ(|V|2)=𝚯(|𝑽|𝟐).\Theta(|V|) + \Theta(|V|) + \Theta(|V|^2) = \mathbf{\Theta(|V|^2)}. (Notice that on sparse graphs where |E|=O(|V|)|E| = O(|V|), the adjacency list runs in Θ(|V|)\Theta(|V|), making the matrix representation quadratically slower).

3. Depth-First Search (DFS)

DFS traverses a graph by exploring as deep as possible along each branch before backtracking. It operates via recursion or an explicit LIFO Stack.

void DFS(const vector<vector<int>>& Adj, int V) {
    vector<int> color(V, 0);               // 0: WHITE, 1: GRAY, 2: BLACK
    for (int u = 0; u < V; u++) {
        if (color[u] == 0)
            DFS_Visit(Adj, u, color);
    }
}

void DFS_Visit(const vector<vector<int>>& Adj, int u, vector<int>& color) {
    color[u] = 1;                          // Discovered: turns GRAY
    for (int v : Adj[u]) {
        if (color[v] == 0)                 // Tree edge (u, v)
            DFS_Visit(Adj, v, color);
    }
    color[u] = 2;                          // Finished: turns BLACK
}

DFS Edge Classification

During DFS on a directed graph, each edge (u,v)(u, v) falls into exactly one of four categories based on the color of vv when (u,v)(u, v) is first explored:

Edge Type Target Color Timestamp Relation Structural Meaning
Tree Edge White d[u]<d[v]<f[v]<f[u]d[u] < d[v] < f[v] < f[u] Discovers a new vertex vv; edge belongs to the DFS forest
Back Edge Gray d[v]≤d[u]<f[u]≤f[v]d[v] \le d[u] < f[u] \le f[v] Connects uu to an ancestor on the current recursion stack (closes a cycle)
Forward Edge Black d[u]<d[v]<f[v]<f[u]d[u] < d[v] < f[v] < f[u] Connects uu to a non-child descendant already explored
Cross Edge Black d[v]<f[v]<d[u]<f[u]d[v] < f[v] < d[u] < f[u] Connects uu to a vertex in another branch or previous tree

[!IMPORTANT] Undirected Graph Edge Property: In an undirected graph, every edge is either a Tree edge or a Back edge. Forward edges and cross edges cannot exist, because any edge connecting to an already finished component would have been traversed when exploring that component.

Step-by-Step Method: Cycle Detection via DFS

  1. Maintain Discovery State: Assign each vertex a state: WHITE (unvisited), GRAY (active on stack), BLACK (completed).
  2. Inspect Incident Edges: When examining edge (u,v)(u, v):
    • If color[v] == GRAY: A cycle exists! vv is an active ancestor of uu, so edge (u,v)(u, v) completes a directed cycle.
    • If color[v] == WHITE: Recurse on vv.
    • If color[v] == BLACK: No cycle closed by this edge.
  3. Cycle Theorem: A directed graph is acyclic if and only if DFS yields zero back edges.
Tutorial 4 Q5: Iterative DFS Implementation Using an Explicit Stack

Question: Rewrite the depth-first search procedure taught in lectures so that it does not use recursion, using an explicit stack instead. Explain how to prevent redundant vertex processing and maintain traversal correctness.

Solution:

  • Algorithmic Challenge: In recursive DFS, a vertex remains on the execution call stack while its neighbors are explored sequentially. In an iterative formulation with an explicit stack, pushing all neighbors at once can push a vertex multiple times if reached via multiple paths.

  • Implementation:

    void Iterative_DFS(const vector<vector<int>>& Adj, int start, int V) {
    vector<bool> visited(V, false);
    stack<int> S;

    S.push(start);

    while (!S.empty()) {
        int u = S.top();
        S.pop();

        if (visited[u]) continue;        // Discard duplicates pushed multiple times
        visited[u] = true;
        // Process vertex u here...

        // Push neighbors in reverse order so the first neighbor is popped first
        for (auto it = Adj[u].rbegin(); it != Adj[u].rend(); ++it) {
            int v = *it;
            if (!visited[v]) {
                S.push(v);
            }
        }
    }
}

  • Correctness & Complexity:

    1. Duplicate Prevention: We check if (visited[u]) continue; immediately upon popping. If vertex uu was pushed via two different predecessors, the first pop marks it visited, and subsequent pops are safely discarded in O(1)O(1).
    2. Neighbor Order Matching: To replicate recursive DFS (which explores neighbors from left-to-right), neighbors must be pushed onto the stack in reverse order (Adj[u].rbegin() to Adj[u].rend()).
    3. Complexity: Each vertex is marked visited once. Each edge is examined at most twice. Total time is Θ(|V|+|E|)\Theta(|V| + |E|) with O(|V|)O(|V|) auxiliary stack memory.

4. Topological Sort

A Directed Acyclic Graph (DAG) represents workflows where edges indicate prerequisite dependencies (u→vu \to v means “uu must precede vv”).

A topological sort of a DAG is a linear ordering of all vertices such that for every directed edge (u,v)(u, v), uu appears before vv.

Step-by-Step Method: Computing Topological Order

Method 1: Kahn’s Algorithm (In-Degree Zero Removal)

  1. Compute in-degree for all v∈Vv \in V.
  2. Enqueue all vertices with in-degree(v)=0\text{in-degree}(v) = 0 into a queue QQ.
  3. While QQ is not empty:
    • Dequeue vertex uu and append to topological output list.
    • For each neighbor v∈Adj[u]v \in \text{Adj}[u], decrement in-degree(v)\text{in-degree}(v) by 1.
    • If in-degree(v)\text{in-degree}(v) drops to 0, push vv into QQ.
  4. Cycle Verification: If output list length <|V|< |V|, the graph contains a cycle (no valid topological order exists).
  5. Time Complexity: Θ(|V|+|E|)\Theta(|V| + |E|).

Method 2: DFS Reverse Finishing Times

  1. Run DFS on the graph.
  2. Whenever a vertex uu finishes exploration (turns BLACK), prepend uu to the front of a linked list.
  3. Upon DFS completion, the linked list represents a valid topological sort.
  4. Correctness: For any directed edge (u,v)(u, v) in a DAG, vv must finish before uu (f[v]<f[u]f[v] < f[u]). Prepending each vertex at its finish time guarantees uu precedes vv.
  5. Time Complexity: Θ(|V|+|E|)\Theta(|V| + |E|).
